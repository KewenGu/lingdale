# Lingdale 灵谷小镇

[![CI](https://github.com/KewenGu/lingdale/actions/workflows/ci.yml/badge.svg)](https://github.com/KewenGu/lingdale/actions/workflows/ci.yml)

一款种田背单词游戏。**以语言学习为里,游戏为表。**

你在灵谷有一座矿洞、一片农场和一个牧场,都是背单词的地方。矿里每条矿脉是一个单词,挖一次答一道题,答对了爆出矿石。
农场是学新词的地方:每株作物是一个单词,浇水就是回答这个词的题。牧场是复习的地方:该复习的词长成牧草,
割一株答一道题,割下的草喂牛羊。开局先去挖矿,挣了钱再把农场和牧场慢慢办起来;之后喜欢哪边就待在哪边,进度是共用的。
你记得越久的词,越容易爆出高级的矿石、割下的草越多,隔得越久才需要再考一次。

## 玩法一览

- **两条完整的路,不分主次。** 见新词、把不会的学会、长期复习,只待在矿洞能做完,农场加牧场也能做完。每个词只有一份进度,随时可以换地方。
- **矿洞:挖矿就是答题。** 每条矿脉是一个词。新词答对一次就算会;答错的词可以在矿里练,连续答对 5 次后隔天再考一次,答对才算数。到期的旧词答对出矿石,矿石的品级就是这个词的掌握度。
- **农场:一株作物就是一个词,浇水就是答题。** 种下时带一个词,可以是答错过的,也可以是没见过的新词;认识的可以换掉,隔天考一次。每个游戏日(现实 12 小时)浇一次水,浇对 5 次收获,最快两天半。
- **牧场:该复习的词长成牧草。** 割一株答一道题。割下的草喂牛和羊,收获的作物可以做成饲料喂鸡;小的养两个季节长大,出牛奶、羊毛、鸡蛋。不回来复习,牲畜会饿、会病,久了会死。
- **掌握度只因为隔了时间的回忆而上升。** 当场连着答对多少次都不算。
- **答错有代价。** 浇水答错不生长并扣一星,连错两次枯萎,连错三次死亡、种子白费。
- **种子决定品种和题型。** 基础种子是看词选义,进阶是看义选词,高级是拼写。越难的越贵,作物也越值钱。
- **掌握度驱动循环。** 掌握度越高,这个词休息越久才回到矿里,从 3 天到 240 天。
- **季节更替。** 现实两周一季,每季有自己的一套作物。

完整规则见[玩法规则](docs/design/02-gameplay.md)。

## 快速开始

需要 Node.js 22 或更高版本。

```bash
npm install
```

```bash
npm run check
```

```bash
npm run sim
```

`npm run check` 依次做类型检查、格式检查和全部测试。`npm run sim` 模拟一个虚拟学习者玩 60 天,
输出每天的新词数、题量、收入和等级,用来在做界面之前验证数值。
