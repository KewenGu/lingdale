# 卡组数据

| 文件 | 是什么 |
|---|---|
| `cet4-1000.json` | 第一个正式词库:大学英语四级常用 1000 词。**生成的文件,不要手改**,改 `cet4-glosses.txt` 后重新生成 |
| `cet4-glosses.txt` | 这 1000 个词的主词性和短释义,一行一个词。卡片上显示的就是它 |
| `gre-1000.json` | GRE 常用 1000 词,只含 GRE 自己的词。同样是生成的 |
| `gre-glosses.txt` | GRE 这 1000 个词的主词性和短释义 |
| `sample-deck.json` | 30 个词的示例,手写的。只给测试和早期调试用 |

## 四级的 1000 个词是怎么来的

1. 词典里标了 `cet4` 的词有 3849 个。去掉同时标了 `zk`(中考)的 695 个:这些词对准备四级的人太基础。
   再去掉带空格、连字符、大写和不足三个字母的,剩 3113 个。
2. 按词频从高到低排(先用当代语料库的词频 `frq`,没有的用英国国家语料库的 `bnc`),取前 1000 个。
   卡组的顺序就是新词出现的顺序,所以越常用的词越先学。
3. 每个词的**主词性和短释义是 AI 写的**(`cet4-glosses.txt`),每条释义不超过 8 个字,最多两条,
   1000 张卡片的释义没有完全相同的。

为什么第 3 步不从词典里按规则截:词典的中文释义很长,几种词性并列,而它记各词性使用占比的那一栏对这批词是空的。
reject、issue、scale 这类名词动词兼用的词,按"取第一个词性的第一条释义"会挑错很多。

## GRE 的 1000 个词是怎么来的

做法和四级一样,只有选词不同:

1. 词典里标了 `gre` 的词有 7504 个。去掉同时标了中考、高考、四级、六级、考研、托福、雅思的,
   再去掉带空格、连字符、大写和不足三个字母的,剩 3455 个。不去掉的话,按词频排在前面的是 defense、designer 这样的词,
   对背 GRE 的人没有难度(见[决策记录 0029](../docs/decisions/0029-gre-deck-for-self-test.md))。
2. 按词频取前 1000 个。
3. 主词性和短释义是 AI 写的(`gre-glosses.txt`),规则和四级相同。

质量上和四级的差别:词典里没有这个词性的 3 个(nudge 作动词、savvy 作形容词、pandemic 作名词);
措辞对不上词典的 238 个,比四级多一倍。一部分是词典的释义旧了(loophole 只有"枪眼"),
但哪些是词典旧、哪些是写错了,没有人逐个核对过。

## 质量:查过什么,没查过什么

下面说的是四级词库;GRE 词库的情况相同,数字见上一节。


- **查过:** 1000 个词的词性都在词典给这个词列的词性里(对不上的 0 个)。格式、长度、重复由脚本和
  `tests/deck.test.ts` 检查。
- **只是机器对了一遍:** 短释义和词典的释义逐条比过,887 个词能在词典里找到相同或互相包含的说法;
  另外 113 个只是措辞不同(脚本运行时会列出来),没有人逐个看过。
- **没查过:** 短释义有没有选对"最常用的那个意思",没有人校对过。**这是这份词库最大的风险**,
  内容原则是"宁可少,不可错"(见[内容](../docs/design/05-content.md#内容原则))。
  练习页答完每道题可以点"释义不准",标记会记下来,用来回头改 `cet4-glosses.txt`。
- **音标不可靠:** 词典用的是一套老的写法,不分 `ɪ` 和 `i`,双元音写成 `əu` 这样。脚本只换了几个符号,没有逐个核对。
  正式上线前要换一个来源。
- 没有例句,没有发音。

## 重新生成

```bash
npx tsx scripts/build-deck.ts <ecdict.csv 的路径> --deck=cet4
```

```bash
npx tsx scripts/build-deck.ts <ecdict.csv 的路径> --deck=gre
```

脚本读 `data/<词库>-glosses.txt`,写出 `data/<词库>-<词数>.json`,并打印词性分布和要复查的词。
缺词、释义重复、释义太长都会直接报错。

- 要加词:加大 `--count`,再加上 `--todo=某个路径`,脚本会把还缺短释义的词连同词典的释义写到那个文件里,照着补进 glosses 文件。
- 要加一个词库:在 `scripts/build-deck.ts` 的 `DECKS` 里加一项(从哪张词表取、去掉哪些更基础的词表),
  用 `--todo` 导出词单,写 glosses 文件;然后把它加进 `tests/deck.test.ts` 和 `scripts/build-web.ts` 的词库列表。

卡片的 `id` 就是单词本身。**已经发出去的卡片不能改 `id`**(存档按它记进度),释义可以改。
