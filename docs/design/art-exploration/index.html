四种画风,同一片农场

下面四张图画的是同一个存档:第 1 年夏季第 3 天,30 块地,其中 12 块等着浇水。只有画风不同。 看完告诉我你选哪个,我再把它写成美术规范。

这些是示意稿,不是成品。 全部用代码绘制(SVG),没有任何 AI 生成的图像。它们用来检验配色、布局,以及各种状态在手机上认不认得出, 不代表每种画风最终能达到的精细程度。用代码画对四个方向并不公平,偏差在哪里写在推荐一节里。

对照七条要求

这是我的判断,不是数据。依据是上面的画面和每种画风的制作方式。圆点越多越符合:三个是强,两个是中,一个是弱。

我的推荐

C 我推荐彩纸拼贴。最终由你决定。

理由

  1. 农场是用来读的。 支柱 2 要求扫一眼看出状态,而地块最多 120 块。缩小检验里 C 和 A 最清楚,B 和 D 掉得最快。 这一条排在最前面,因为它直接关系到产品目标,不是审美偏好。
  2. 一个人做。 12 种作物、5 个形态、3 种健康状态,还要有生长、枯萎、收获的动画,而路线图里说这部分"决定了答题是享受还是忍受"。 在 C 里,这些都是同一组形状的换色、旋转和缩放,不用为每个状态多画一张;A 要多画像素变体,B 要逐帧画或接受作物不动,D 要建模。
  3. AI 协助的方式更稳。 C 的素材可以由代码或矢量工具直接产出,这份示意稿本身就是这样来的。它不经过"生成一张图再去修",所以没有逐张风格漂移的问题。
  4. 正文是单词。 答题界面上的单词、音标、释义必须好读。C、B、D 用的都是普通字体,A 的像素字体在这里吃亏。

选 C 要付的代价

它是四个方向里最容易被看成"一个应用"的。治愈感不是自带的,要靠配色、形状和纸的质感经营; 在小红书上它清楚、醒目,但不如 B 让人想停下来看。 如果你看完觉得 C"干净但没感觉",那这个代价就是真的,不该选它。

其他三个

  • B 水彩绘本是第二选择。 气质上它最贴"治愈的田园小镇",离修仙最远。如果你自己愿意画,或者把画面气质放在第一位,选它是合理的; 代价是要为状态另外设计一层清晰的标记,并且长期和"成套一致"较劲。
  • A 像素菜园没有被推荐,不是因为不好看。"像素加种田"这个组合里已经有一个人人都知道的作品, 我们很难不被拿来比较,而选题库里本来就有一篇要讲"为什么不能照搬它的规则"。再加上中文像素字体对答题界面不友好。
  • D 低多边形沙盘在短视频里最出彩,但遮挡损害可辨认度,建模和 3D 管线对一个人来说太重。

一个可以考虑的折中

C 的形状和状态画法,加上 B 的纸纹、柔和配色和手工的不规则。也就是:作物仍然是可以用变换驱动的纸片, 但边缘带一点手剪的不整齐,颜色更柔,表面有水彩纸的颗粒。如果你觉得 C 太冷、B 太难做,告诉我,我照这个再出一版。

这个推荐的局限

  • 示意稿偏向 C。 代码最擅长画的恰好是纯色的几何形状。B 的水彩和 D 的 3D 用真正的工具做会比这里好看得多,A 由熟练的像素画师来摆也会更精致。 所以比较"好不好看"时请给 C 打个折扣;比较"认不认得出"相对公平,因为那主要取决于明暗对比和轮廓。
  • 审美由你决定。 我能判断的是可辨认度和产能,判断不了哪个更打动你和小红书上的目标用户。后者正是"这几种画风,你更喜欢哪个"这条内容要问观众的。
  • 有些依据没有实测。 关于 AI 图像工具画不好像素画、AI 对 3D 建模帮助有限,是我对这类工具的了解,没有在这个项目里试过。 微信小游戏主包 4MB 的上限来自多份第三方资料,没有核对官方文档。

画的过程中核实的一件事

画"快收获"这个状态时,我先以为"开花"就等于"快收获"。按规则核对后发现不是: 只有新词要浇对 5 次、依次经过五个形态;掌握度高的旧词浇对 1 到 3 次就收获,会跳过后面的形态。

用现有的模拟器跑了一下(默认参数,正确率 85%,每天开两次,3 到 5 个随机种子取平均,第 7 天到第 365 天): 田里下一次浇对就能收获的作物占 20% 到 38%,而处在开花形态的只占 7% 到 18%。 也就是说,大部分快收获的作物看起来并不像快收获。

所以四份稿里都加了一个独立的"浇对就收获"标记(地块左上角)。这是在不改规则的前提下,靠美术补上的。 同一次模拟还显示,任何时候田里大约有四分之一到三分之一的作物是"种子"形态,所以种子这个最不起眼的形态值得认真画。

这些数字来自模拟,不是真实玩家的数据。我还验证了另一个猜想:"玩到后期,田里会不会大部分是种子"。 模拟不支持这个猜想,各形态的占比在一年内都比较稳定。
