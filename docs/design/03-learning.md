# 学习设计

[玩法规则](02-gameplay.md)说的是游戏怎么玩。本文说的是每条规则在学习上起什么作用,也就是"里"的部分。

改任何规则之前,先在这里确认它对学习的影响。

## 我们依赖的三条记忆规律

1. **主动回忆比重复阅读有效。** 努力从脑子里把答案提取出来,这个过程本身在加固记忆。
2. **间隔开的复习比集中复习有效。** 同样的次数,分散到几天、几周里,记得更久。
3. **间隔应该逐渐拉长。** 在快要忘记的时候回忆一次效果最好;记得越牢,下一次可以隔得越久。

这三条是通用的结论,不是本项目的发现。本项目自己的数据目前只有模拟,还没有真人的学习数据。

## 学一个词要做的三件事

见到它、把不会的学会、之后隔着时间复习。有两条完整的路,玩家可以只走一条,也可以混着走:

| | 矿洞 | 农场和牧场 | 学习上是什么 |
|---|---|---|---|
| 见新词 | 挖新矿脉,先答一道题 | 农场:种下时看到这个词,认识的换掉、隔天考一次 | 摸底:会的词不用学,把时间留给不会的 |
| 把不会的学会 | 练习:连对 5 次,隔天再考 | 农场:种下时看单词卡片,之后每个游戏日浇一次水,浇对 5 次 | 初学:先看答案,再隔着时间回忆 |
| 长期复习 | 挖到期的旧矿脉 | 牧场:割牧草 | 逐渐拉长的间隔复习 |

几个地方共用同一份进度和同一条底线:**掌握度只因为隔了至少一个游戏日的回忆而上升。**
矿里的练习当场连对多少次都不算,算数的是隔天那一次;田里每次浇水之间至少隔 6 小时、跨一个游戏日;
复习的旧词都是休息期满了才出现。

## 规则与学习作用的对应

| 游戏规则 | 学习上的作用 |
|---|---|
| 挖矿、浇水、割牧草都是答题 | 每次都是一次主动回忆 |
| 新词在矿里先答一道题;在田里认识的可以换掉,隔天考一次 | 摸底:已经会的词不用再学。两边都要答对一道题才算会,自己说认识不算 |
| 种下时展示单词卡片 | 第一次正式学习这个词 |
| 浇对 5 次才收获,每个游戏日只能浇一次,至少隔 6 小时 | 初学阶段的密集巩固,两天半内隔开回忆 5 次 |
| 矿里的练习不改掌握度,练出去后隔天再考 | 当场反复只是短期记住,隔天还答得出才算数 |
| 答对或收获后休息 3、7、15、30 天再出现 | 逐渐拉长的间隔复习 |
| 同一个词休息期内不会出现在矿里和牧场的草地上 | 强制隔开,"连续答对"不可能靠短时记忆刷出来 |
| 记得越久的词越容易出高级矿石、割下的牧草越多;牛养得起几头,看有多少词在按时复习 | 奖励跟着长期记忆走 |
| 草地上有几株草,就是有几个词该复习了 | 该复习多少一眼看得见,不用玩家自己记 |
| 牛要吃草,草只能靠复习得来;不复习牛会饿、会病、会死 | 给按时复习一个看得见的理由。受罚的只是牛,词的进度不因缺席变差 |
| 复习答错的旧词降两级、进词袋 | 忘了的词重新学一遍,间隔缩短 |
| 浇水答错后当场重复练习到答对 | 立即纠正,但不计入成绩 |
| 矿脉先出到期的旧词,再出新词;田里有旧词没复习时种下不给新词 | 先保住已学的,再学新的。两边都有,不然换个地方就能绕开复习 |
| 词袋最多比空地多装 10 个词 | 限制等着学的词数,防止贪多 |
| 三种作物对应三种题型,由易到难 | 从再认到回忆,提取难度逐级提高 |

## 一个词的两种路径

**本来就会的词**:第一次见就答对(在矿里挖到,或者种田时换掉、隔天考过),之后每隔 3、7、15、30 天确认一次,
每次一道题,在矿里挖或者在牧场割草都行。它从不需要种。

**不会的词**:在矿里答错,或者种田时直接种下。然后有两条路把它学会:种在田里,两天半内浇对 5 次水收获;
或者在矿里练到连对 5 次,隔天再考一次。之后和会的词一样,按间隔复习。

田里的两天半、矿里的练习,都只能说明短期记住了。词汇能不能进入长期记忆,由之后一次次隔着时间的确认决定。
所以"收获了一株五星作物"不等于"掌握了这个词",掌握度才是真正的进度,而它需要几个月才能升上去。

## 摸底为什么值得做

最早的设计里,每个新词不管会不会都要种下、浇 5 次水。背四级词汇的人其实认识其中不少词,这部分时间是浪费的。

现在每个新词先花一道题摸底:在矿里是当场答,在田里是换掉之后隔天答。模拟中,一个本来认识 40% 词汇的学习者,不扩建地块,60 天能过八九百个词,
每天约 110 道题;改之前同样不扩建只能过 203 个词(两次模拟的学习者模型不同,只能比量级)。
差别主要来自两点:会的词不再占用田地,复习不再占用田地。

## 三种题型

| 题型 | 学习类型 | 难度 |
|---|---|---|
| 看词选义 | 再认:看到单词,认出意思 | 低 |
| 看义选词 | 再认:看到意思,认出单词的拼写 | 中 |
| 拼写 | 回忆:看到意思,自己写出单词 | 高 |

再认比回忆容易,也更浅。会"看词选义"只说明阅读时能认出这个词;会拼写才说明能主动使用。

田里的题型由种子的品种决定,玩家自己买、自己选;越难的作物卖得越贵,以此鼓励玩家往难的方向走。
矿里目前只出看词选义。

**全部是客观题。** 早期版本有"看词回忆,然后自己点记得或忘了"的自评题,已经去掉。
原因是答错有扣星和作物死亡的代价,自评题会让玩家有很强的动机直接点"记得"。

## 负担控制

每天要答多少题,由这几个机制共同限制:

- **答错的额度。** 新词还能答错几次,等于空地块数加 10 减去词袋里的词数,用完就不再出没见过的新词。
  田里同时在学的词不会超过地块数,词袋里等着学的词也不会无限堆积。
- **练习不算数,隔天再考才算数。** 词袋装满之后可以在矿里练词袋里的词。练习里连续答对 5 次只说明短期记住了,
  所以它不改掌握度、不出矿石;这个词离开词袋后要隔一个游戏日再考一次,那一次答对才升级。
  这样玩家想多玩的时候有题可做,而"掌握"仍然只来自隔着时间的回忆。
- **复习不设限。** 到期的旧词随时能挖,田满了也一样。复习不会制造新的负担,它只是把已经忘掉的词找出来;
  拦着不让复习,只会让遗忘晚几天才被发现。
- **复习优先。** 矿里先出到期的旧词,旧词多的时候新词自然变少。
- **休息期。** 一个词答对之后要隔几天到几个月才能再挖,刷不了题。

挖新词本身没有每日上限,所以学得快的人可以走得很快。负担的上限来自"不会的词要占地"。

模拟中,见过的词越多,到期的复习越多,留给新词的题就越少:默认的学习者每次答 30 题,到第 30 天这 30 题已经全是复习。
忘得快的学习者复习时答错的多,要重学的词多,新词也相应变少。也就是说负担是自己收敛的,不是越欠越多。

## 错误的处理

| 情况 | 游戏表现 | 学习上的含义 |
|---|---|---|
| 矿里答错新词 | 进词袋,去田里种 | 这是一个要学的词。答错不是惩罚,是发现了要学的东西 |
| 矿里答错旧词 | 掌握度降两级,进词袋 | 忘了,重新学一遍,之后间隔缩短 |
| 浇水答错一次 | 不生长,扣一星 | 还没记住,下个游戏日再考 |
| 收获三星以下 | 掌握度降一级,半天到几天后回到矿里 | 学得不牢,很快再确认 |
| 浇水连续答错三次 | 作物死亡,掌握度降两级,回到矿里 | 基本没记住,重新来过 |
| 缺席几天 | 无惩罚 | 回来后照常挖矿和浇水 |

## 已知的弱点

这些是当前设计在学习效果上的风险,如实记录,等真人数据来验证或推翻。

1. **矿里的选择题可以蒙。** 四选一有 25% 的概率蒙对,不认识的新词会被当成认识的,拿到最低级的矿石,
   3 天后才再考。模拟里(默认场景,60 天)不认识的新词蒙对了约 120 次。按记忆模型,这些词看过一次答案,
   3 天后还有六成想得起来,其余的在复习时答错、进词袋;结束时游戏算作掌握、而学习者把握不到一半的词只有个位数。
   所以它主要的代价是这些词晚学几天,而不是长期把不会的词算成会的。这依赖模型里最没把握的一环
   (只看过一次答案能记多久),真人数据出来后要核对。
   只算第一次作答(排除选项后选对的不算)堵住的是"试出来的答案",堵不住第一次就蒙对的。
   可以进一步缓解的办法:矿里加一个"不认识"按钮;新词答对后第一次休息缩短;或者矿里改用更难蒙的题型。
2. **摸底只考了"认得",没考"会用"。** 在矿里看词选义答对的词,可能并不会拼写、不会在句子里用,却不会进田。
3. **种田可能不是必需的,浇 5 次可能偏多。** 按模拟里的记忆模型,词袋里的词在矿里练出去、隔天再考,
   效果和种田差不多;浇水从第 2 次起正确率就在 92% 以上。也就是说田里的两天半有一部分是在考已经记住的东西。
   这两条都只是模型的说法,见[数值与平衡](04-economy-balance.md#这些数字说明了什么)。
4. **题型由玩家自选。** 玩家可能一直买最便宜的基础种子,学到的只是认读能力。
   价格倍率是否足以引导玩家尝试更难的题型,还不知道。
5. **学得吃力的人反馈差。** 他们的作物星级低一些,要重学的词多一些。不过按模型,差距没有之前估的大:
   忘得快两倍的学习者五星作物仍有 67%,作物死亡只有 1%。答错在矿里也有正面的出口(得到一个要种的词)。
6. **忘掉一个记了很久的词,代价是重种 5 次水。** 对高掌握度的词来说可能偏重。
7. **干扰项是随机取的。** 没有刻意选形近词或义近词,选择题的区分度有限。
8. **模拟的局限。** 模拟里的学习者按公开的 FSRS 记忆模型记和忘,参数是别人的数据拟合出来的,不是我们玩家的;
   学习者只买基础种子;"本来认识多少词"是一个假设的比例。完整的假设见[数值与平衡](04-economy-balance.md#怎么验证数值)。

## 以后想用真实数据回答的问题

- 学习者本来认识词库里多少词?第一次见就答对的比例是多少,其中有多少是蒙的(之后复习时答错)?
- 新词第一次休息(3 天)回来时的正确率是多少?
- 各掌握度的词回来时的正确率是否都在 80% 到 90% 之间?低于这个范围说明间隔太长,高于说明太短。(模型给的是 90% 上下。)
- 第 1 到第 5 次浇水的正确率各是多少?模型说第 2 次起就在 92% 以上,如果真人也是这样,浇水次数可以减。
- **只看过一次答案的词,半天后还记得多少?** 模型说 88%。这是模型最没把握的一环,而"练习和种田差不多"的结论最依赖它。
- 练出词袋的词,隔天再考和 3 天后复习的正确率各是多少?和种过的词比差多少?
- 玩家实际选择三种题型的比例是多少?
- 每天题量到多少时,玩家开始流失?

每次作答都记录在日志里(`ReviewLog`),包含在矿里还是田里、是不是第一次见、当时的掌握度、题型和用时,就是为了回答这些问题。
