# 学习设计

[玩法规则](02-gameplay.md)说的是游戏怎么玩。本文说的是每条规则在学习上起什么作用,也就是"里"的部分。

改任何规则之前,先在这里确认它对学习的影响。

## 我们依赖的三条记忆规律

1. **主动回忆比重复阅读有效。** 努力从脑子里把答案提取出来,这个过程本身在加固记忆。
2. **间隔开的复习比集中复习有效。** 同样的次数,分散到几天、几周里,记得更久。
3. **间隔应该逐渐拉长。** 在快要忘记的时候回忆一次效果最好;记得越牢,下一次可以隔得越久。

这三条是通用的结论,不是本项目的发现。本项目自己的数据目前只有模拟,还没有真人的学习数据。

## 规则与学习作用的对应

| 游戏规则 | 学习上的作用 |
|---|---|
| 浇水就是答题 | 每次浇水都是一次主动回忆 |
| 每个游戏日只能浇一次,至少隔 6 小时 | 强制把同一个词的回忆间隔开,不能一口气刷完 |
| 新词浇对 5 次才收获 | 初学阶段的密集巩固,两天半内回忆 5 次 |
| 收获后休息 3、7、15、30 天再回来 | 逐渐拉长的间隔复习 |
| 掌握度越高,回来时浇水次数越少 | 熟词只需确认还记得,不浪费时间 |
| 收获星级调整掌握度 | 用实际表现决定下一次间隔,而不是固定日程 |
| 答错后当场重复练习到答对 | 立即纠正,但不计入成绩 |
| 该复习的旧词优先于新词 | 先保住已学的,再学新的 |
| 地块数量有限 | 限制同时在学的词数,防止贪多 |
| 三种题型由易到难 | 从再认到回忆,提取难度逐级提高 |

## 一个词的两个阶段

**初学阶段(掌握度 0):** 浇对 5 次,最快两天半。
这只能说明短期记住了。两天半内答对五次,不代表两周后还记得。

**长期阶段(掌握度 1 以上):** 休息、回来、再确认,间隔从 3 天一路拉长到 240 天。
词汇能不能进入长期记忆,由这个阶段决定。

所以游戏里"收获了一株五星作物"不等于"掌握了这个词"。掌握度才是真正的进度,而它需要几个月才能升上去。

## 三种题型

| 题型 | 学习类型 | 难度 |
|---|---|---|
| 看词选义 | 再认:看到单词,认出意思 | 低 |
| 看义选词 | 再认:看到意思,认出单词的拼写 | 中 |
| 拼写 | 回忆:看到意思,自己写出单词 | 高 |

再认比回忆容易,也更浅。会"看词选义"只说明阅读时能认出这个词;会拼写才说明能主动使用。

目前由玩家自己选种哪种作物,越难的作物卖得越贵,以此鼓励玩家往难的方向走。

**全部是客观题。** 早期版本有"看词回忆,然后自己点记得或忘了"的自评题,已经去掉。
原因是答错有扣星和作物死亡的代价,自评题会让玩家有很强的动机直接点"记得"。

## 负担控制

每天要答多少题,由三个机制共同限制:

- **地块数。** 同时在长的作物数量有上限。
- **复习优先。** 种子先用来种该复习的旧词,旧词多的时候新词自然变少。
- **种子供应。** 每个游戏日能拿到的种子有限。

效果是学得吃力的人新词自动变少。模拟中正确率 70% 的学习者,每天新词是正确率 85% 者的六成左右,题量相近。

## 错误的处理

| 情况 | 游戏表现 | 学习上的含义 |
|---|---|---|
| 答错一次 | 不生长,扣一星 | 这个词还没记住,下个游戏日再考 |
| 这一轮答错较多,收获三星以下 | 掌握度降一级 | 间隔缩短,更早回来 |
| 连续答错三次 | 作物死亡,掌握度降两级 | 这个词基本忘了,很快重新来过 |
| 缺席几天 | 无惩罚 | 回来后照常浇水 |

## 已知的弱点

这些是当前设计在学习效果上的风险,如实记录,等真人数据来验证或推翻。

1. **初学阶段压缩得比较紧。** 新词两天半收获,然后休息 3 天。第一次长间隔之后的遗忘率可能偏高。
   系统能兜住(答错就降级、间隔缩短),但会损失一些效率。
2. **选择题可以猜。** 四选一有 25% 的概率蒙对。全程只种基础作物的玩家,掌握度会被高估。
3. **题型由玩家自选。** 玩家可能一直停留在最容易的"看词选义",学到的只是认读能力。
   价格倍率是否足以引导玩家尝试更难的题型,还不知道。
4. **学得吃力的人反馈最差。** 他们的作物星级低、死亡多、收入少。这在学习上是如实反映,但可能把他们劝退。
5. **干扰项是随机取的。** 没有刻意选形近词或义近词,选择题的区分度有限。
6. **模拟不区分题型难度。** 模拟里的学习者只种基础作物,而且每个词的答错概率是固定的,不随间隔变长而上升。

## 以后想用真实数据回答的问题

- 新词第一次休息(3 天)回来时的正确率是多少?
- 各掌握度的词回来时的正确率是否都在 80% 到 90% 之间?低于这个范围说明间隔太长,高于说明太短。
- 玩家实际选择三种题型的比例是多少?
- 每天题量到多少时,玩家开始流失?

每次作答都记录在日志里(`ReviewLog`),包含当时的掌握度、题型和用时,就是为了回答这些问题。
