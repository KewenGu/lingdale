# 学习设计

[玩法规则](02-gameplay.md)说的是游戏怎么玩。本文说的是每条规则在学习上起什么作用,也就是"里"的部分。

改任何规则之前,先在这里确认它对学习的影响。

## 我们依赖的三条记忆规律

1. **主动回忆比重复阅读有效。** 努力从脑子里把答案提取出来,这个过程本身在加固记忆。
2. **间隔开的复习比集中复习有效。** 同样的次数,分散到几天、几周里,记得更久。
3. **间隔应该逐渐拉长。** 在快要忘记的时候回忆一次效果最好;记得越牢,下一次可以隔得越久。

这三条是通用的结论,不是本项目的发现。本项目自己的数据目前只有模拟,还没有真人的学习数据。

## 规则与学习作用的对应

| 游戏规则 | 学习上的作用 |
|---|---|
| 挖矿和浇水都是答题 | 每次都是一次主动回忆 |
| 新词先在矿里答一道题 | 摸底:已经会的词不用再学,把时间留给不会的词 |
| 矿里答错的词才进田 | 学习集中在真正不会的词上 |
| 种下时展示单词卡片 | 第一次正式学习这个词 |
| 浇对 5 次才收获,每个游戏日只能浇一次,至少隔 6 小时 | 初学阶段的密集巩固,两天半内隔开回忆 5 次 |
| 答对或收获后休息 3、7、15、30 天再回到矿里 | 逐渐拉长的间隔复习 |
| 同一个词休息期内不能再挖 | 强制隔开,"连续答对"不可能靠短时记忆刷出来 |
| 矿石品级等于掌握度 | 奖励跟着长期记忆走 |
| 在矿里答错旧词,降级并回到田里 | 忘了的词重新学一遍,间隔缩短 |
| 浇水答错后当场重复练习到答对 | 立即纠正,但不计入成绩 |
| 矿脉先出到期的旧词,再出新词 | 先保住已学的,再学新的 |
| 答错的次数不能超过空地块数 | 限制同时在学的词数,防止贪多 |
| 三种作物对应三种题型,由易到难 | 从再认到回忆,提取难度逐级提高 |

## 一个词的两种路径

**本来就会的词**:在矿里第一次见就答对,之后每隔 3、7、15、30 天在矿里确认一次,每次一道题。它从不进田。

**不会的词**:在矿里答错,进词袋,种到田里。两天半内浇对 5 次水收获,然后和会的词一样,回到矿里按间隔复习。

田里的两天半只能说明短期记住了。词汇能不能进入长期记忆,由之后在矿里一次次隔着时间的确认决定。
所以"收获了一株五星作物"不等于"掌握了这个词",掌握度才是真正的进度,而它需要几个月才能升上去。

## 摸底为什么值得做

之前的设计里,每个新词不管会不会都要种下、浇 5 次水。背四级词汇的人其实认识其中不少词,这部分时间是浪费的。

现在每个新词先花一道题摸底。模拟中,一个本来认识 40% 词汇的学习者,不扩建地块,60 天能过 722 个词,
每天约 123 道题;改之前同样不扩建只能过 203 个词。差别主要来自两点:会的词不再占用田地,复习不再占用田地。

## 三种题型

| 题型 | 学习类型 | 难度 |
|---|---|---|
| 看词选义 | 再认:看到单词,认出意思 | 低 |
| 看义选词 | 再认:看到意思,认出单词的拼写 | 中 |
| 拼写 | 回忆:看到意思,自己写出单词 | 高 |

再认比回忆容易,也更浅。会"看词选义"只说明阅读时能认出这个词;会拼写才说明能主动使用。

田里的题型由种子的品种决定,玩家自己买、自己选;越难的作物卖得越贵,以此鼓励玩家往难的方向走。
矿里目前只出看词选义。

**全部是客观题。** 早期版本有"看词回忆,然后自己点记得或忘了"的自评题,已经去掉。
原因是答错有扣星和作物死亡的代价,自评题会让玩家有很强的动机直接点"记得"。

## 负担控制

每天要答多少题,由这几个机制共同限制:

- **答错的额度。** 新词还能答错几次,等于空地块数加 10 减去词袋里的词数,用完就不再出没见过的新词。
  田里同时在学的词不会超过地块数,词袋里等着学的词也不会无限堆积。
- **练习不算数,隔天再考才算数。** 词袋装满之后可以在矿里练词袋里的词。练习里连续答对 5 次只说明短期记住了,
  所以它不改掌握度、不出矿石;这个词离开词袋后要隔一个游戏日再考一次,那一次答对才升级。
  这样玩家想多玩的时候有题可做,而"掌握"仍然只来自隔着时间的回忆。
- **复习不设限。** 到期的旧词随时能挖,田满了也一样。复习不会制造新的负担,它只是把已经忘掉的词找出来;
  拦着不让复习,只会让遗忘晚几天才被发现。
- **复习优先。** 矿里先出到期的旧词,旧词多的时候新词自然变少。
- **休息期。** 一个词答对之后要隔几天到几个月才能再挖,刷不了题。

挖新词本身没有每日上限,所以学得快的人可以走得很快。负担的上限来自"不会的词要占地"。

模拟中正确率 70% 的学习者,矿洞有 87% 的时候因为田满了而关着,每天见到的新词是正确率 85% 者的四成左右,
题量相近。也就是说学得吃力的人新词自动变少,而不是越欠越多。

## 错误的处理

| 情况 | 游戏表现 | 学习上的含义 |
|---|---|---|
| 矿里答错新词 | 进词袋,去田里种 | 这是一个要学的词。答错不是惩罚,是发现了要学的东西 |
| 矿里答错旧词 | 掌握度降两级,进词袋 | 忘了,重新学一遍,之后间隔缩短 |
| 浇水答错一次 | 不生长,扣一星 | 还没记住,下个游戏日再考 |
| 收获三星以下 | 掌握度降一级,半天到几天后回到矿里 | 学得不牢,很快再确认 |
| 浇水连续答错三次 | 作物死亡,掌握度降两级,回到矿里 | 基本没记住,重新来过 |
| 缺席几天 | 无惩罚 | 回来后照常挖矿和浇水 |

## 已知的弱点

这些是当前设计在学习效果上的风险,如实记录,等真人数据来验证或推翻。

1. **矿里的选择题可以蒙。** 四选一有 25% 的概率蒙对,不认识的新词会被当成认识的,拿到最低级的矿石,
   3 天后才再考。连续蒙对的概率很快趋近于零,所以最终会被筛出来,但会晚几天到十几天才开始学。
   模拟里(默认场景,60 天)不认识的新词蒙对了 119 次,到第 60 天还被算作掌握的只剩 6 个,没有一个到"牢固"。
   所以它主要的代价是这些词晚学几天、白拿了一两块低级矿石,而不是长期把不会的词算成会的。
   这个结论依赖两个假设:每次复习蒙对的概率仍是 25%,以及玩家每次都蒙。真人数据出来后要核对。
   只算第一次作答(排除选项后选对的不算)堵住的是"试出来的答案",堵不住第一次就蒙对的。
   可以进一步缓解的办法:矿里加一个"不认识"按钮;新词答对后第一次休息缩短;或者矿里改用更难蒙的题型。
2. **摸底只考了"认得",没考"会用"。** 在矿里看词选义答对的词,可能并不会拼写、不会在句子里用,却不会进田。
3. **初学阶段压缩得比较紧。** 新词两天半收获,然后休息 3 天。第一次长间隔之后的遗忘率可能偏高。
   系统能兜住(答错就降级、重新种),但会损失一些效率。
4. **题型由玩家自选。** 玩家可能一直买最便宜的基础种子,学到的只是认读能力。
   价格倍率是否足以引导玩家尝试更难的题型,还不知道。
5. **学得吃力的人反馈差。** 他们的作物星级低、死亡多,矿洞经常关着。这在学习上是如实反映,但可能把他们劝退。
   好的一面是答错在矿里有了正面的出口(得到一个要种的词),而不只是惩罚。
6. **忘掉一个记了很久的词,代价是重种 5 次水。** 对高掌握度的词来说可能偏重。
7. **干扰项是随机取的。** 没有刻意选形近词或义近词,选择题的区分度有限。
8. **模拟的局限。** 模拟里的学习者只买基础种子;每个词的答错概率是固定的,不随间隔变长而上升;
   "本来认识多少词"是一个假设的比例。

## 以后想用真实数据回答的问题

- 学习者本来认识词库里多少词?第一次见就答对的比例是多少,其中有多少是蒙的(之后复习时答错)?
- 新词第一次休息(3 天)回来时的正确率是多少?
- 各掌握度的词回来时的正确率是否都在 80% 到 90% 之间?低于这个范围说明间隔太长,高于说明太短。
- 玩家实际选择三种题型的比例是多少?
- 每天题量到多少时,玩家开始流失?

每次作答都记录在日志里(`ReviewLog`),包含在矿里还是田里、是不是第一次见、当时的掌握度、题型和用时,就是为了回答这些问题。
