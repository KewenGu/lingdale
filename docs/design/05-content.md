# 内容

内容指玩家要学的东西:卡片和卡组。游戏规则不认识"英语"或"单词",只认识卡片。

## 卡片与卡组

一张**卡片**是一个要记住的知识点,有正面和背面(`Card`):

| 字段 | 必填 | 说明 | 例子 |
|---|---|---|---|
| `id` | 是 | 卡组内唯一 | `abandon` |
| `front` | 是 | 要学的内容 | `abandon` |
| `back` | 是 | 它的意思 | `v. 放弃;抛弃` |
| `phonetic` | 否 | 音标 | `/əˈbændən/` |
| `pos` | 否 | 词性。出选择题时干扰项只取同词性的 | `v` |
| `alt` | 否 | 这个词的全部释义。不显示,只用来排除意思相近的干扰项 | `["放弃","抛弃","遗弃"]` |
| `example` | 否 | 例句 | |
| `exampleTranslation` | 否 | 例句翻译 | |
| `audioKey` | 否 | 发音资源的键,不是网址 | |

一个**卡组**是一组有顺序的卡片(`Deck`):`id`、`name`、`version`、`cards`。

新词按卡片在卡组里的顺序依次出现,所以卡组的顺序就是学习顺序。按词频从高到低排是最自然的做法。

## 题目怎么从卡片生成

题目不需要单独编写,全部由卡片自动生成:

| 题型 | 题面 | 答案 | 干扰项 |
|---|---|---|---|
| 看词选义 | `front` | `back` | 同卡组其他卡片的 `back` |
| 看义选词 | `back` | `front` | 同卡组其他卡片的 `front` |
| 拼写 | `back` | `front` | 无 |

卡片带 `pos` 和 `alt` 时,干扰项不是随便取的:

- 只取**同词性**的卡片。四个选项词性各不相同的话,认得出题面是个形容词就能排除掉名词和动词。
- 不取**意思重合**的卡片:两张卡片的 `alt` 里有一条相同、或者一条包含另一条(放弃 / 放弃的),就不互相当干扰项。
  obtain 和 gain 都有"获得"的意思,放进同一题会有两个选项都算对。
- 同词性的卡片不够凑齐选项时(介词、数词在卡组里只有几个),放宽到别的词性,仍然不取意思重合的。
- 没有这两个字段的卡组(比如玩家以后自己导入的)照旧在整个卡组里随机取。

这条规则是量出来的:四级 1000 词上,一个不认识任何词、只会看后缀猜词性的答题者,干扰项随机取时能蒙对 36% 到 40%,
同词性之后是 25%(`npm run guess`,见[数值与平衡](04-economy-balance.md#8-蒙对的词))。

这意味着卡组的质量直接决定题目的质量:

- `back` 要简短明确。太长的释义在选择题里一眼就能和别的选项区分开。
- 同一卡组里不应有 `back` 完全相同的卡片。系统会避免把相同的释义放进同一题,但它们在"看义选词"里无法区分。
- 卡组至少要有 4 张 `back` 互不相同的卡片才能出选择题,否则会退回成拼写题。

## 现有内容

**`data/cet4-1000.json`:大学英语四级常用 1000 词。** 第一个正式词库,2026-11-22 做的。

- 选词、顺序(按词频)和音标来自开源词典 ECDICT(MIT 许可,可以商用,要保留版权声明)。
  取的是四级词表里不属于中考词表的词,按词频排前 1000 个。
- 每张卡片有 `front`、`back`、`phonetic`、`pos`、`alt`。`back` 是"主词性 + 一到两条短释义",每条不超过 8 个字。
- **主词性和短释义是 AI 写的,没有人逐个校对过。** 和词典机器对过一遍:词性对不上的 0 个,释义措辞对不上的 113 个。
  这是现在最大的内容风险。练习页答完每题可以标记"释义不准",用来回头改。
- **音标不可靠**(词典用的是老写法),上线前要换来源。没有例句,没有发音。

来源、许可、生成步骤和查过什么没查过什么,见 [`data/README.md`](../../data/README.md)。
为什么短释义不从词典里按规则截,见[决策记录 0026](../decisions/0026-first-real-deck-and-same-pos-distractors.md)。

`data/sample-deck.json`:30 个四级难度的英语单词,手工编写,只有 `front`、`back`、`phonetic`。
它只用于测试和早期调试,不是正式词库。

## 还没做的内容

- **校对。** 1000 条短释义逐个过一遍,先从练习页上被标记的词开始。
- **音标换来源,补发音和例句。** 从哪里来还没有定,许可要逐个核对。
- **四级剩下的词。** 四级词表里还有两千多个词没做;中考词表里的 695 个基础词要不要补,要负责人定。

**之后的方向**(不在当前范围内):六级、考研、雅思等更多英语词库;其他语言;允许玩家导入自己的卡组。

## 内容的技术约束

- **词库不打进安装包。** 小游戏平台的包体限制只有几 MB,词库和音频必须按卡组从服务器按需下载。
- **发音资源用键引用。** `audioKey` 存的是资源的键,由平台层决定从哪里加载。
- **卡组升级要兼容旧存档。** 存档按卡片 `id` 记录进度。新版本卡组可以增加卡片、修改释义,但不能改变已有卡片的 `id`。
- **单词可能撞上保留名。** 像 `constructor` 这样的词会被用作对象的键,代码里读取词的状态必须走 `getState`。

## 内容原则

- **准确优先。** 释义、音标错了,玩家学到的就是错的。宁可少,不可错。
- **一张卡片一个重点。** 多义词只取最常用的一两个义项,其余的以后作为单独的卡片。
- **对学习者诚实。** 不因为某个词难出题就把它从词库里拿掉。
