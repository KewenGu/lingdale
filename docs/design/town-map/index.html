山谷里的小镇

小镇地图是游戏的总入口。这一稿画的是站在镇子前面的山头上往下看到的样子:脚下是山头和路牌,近处是木栅栏围起来的农场和山脚的矿洞, 过一座小桥是围着广场的镇子,再远是湖,最远是一层层的山。近的大,远的小;近的压着远的。

示意稿,不是成品,也还没有定稿。 全部用代码绘制(SVG),没有使用图像生成工具。画面不读取游戏数据,数字是手写的示意。等负责人看过再改。
现在真的能进的只有四处:矿洞、农场、牧场、商店,它们下面有带状况的名牌。 家、旅店、饭店、电影院、镇公所、中心广场、居民的家、湖边钓鱼都还没有设计:它们画出来了、也上了色,但下面不写名字(负责人定的)。
这是第四轮。第一轮的三种构图被负责人全部否掉(太简单、太机械,横平竖直),留在方案比较页作记录; 第二轮先画地形再摆东西,负责人说方向对了但不够精致:房子没有特色,景致、前后、错落、阴影都太粗; 第三轮改成从山头上远看,负责人说镇上还是太简单、缺装饰,于是第四轮给镇上加了石板路、石桥、台阶、路灯、花坛、行道树这些细节。
