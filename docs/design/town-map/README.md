# 小镇地图

小镇地图精修稿的方案、绘制代码和记录。地图是游戏的总入口([决策记录 0018](../../decisions/0018-town-map-as-hub.md))。

**现在的状态:精修稿改到第四轮,等项目负责人看。** 还没有定稿,所以美术规范引用的参考图仍是 [`../mine-screens/`](../mine-screens/README.md)
里的那一稿([`town.png`](../art-direction/town.png)),导出页和决策记录也还没有做。

背景:地图原来只有一稿,只画了矿洞、农场、商店和一个"家",没有比较过别的排法。2026-11-21 负责人给了新的想法:
平坦山谷里的一个小镇;下面是木栅栏围起来的农场(家、田地、牧场、动物小屋、鸡舍),中间是镇子(商店、旅店、饭店、电影院、镇公所、
中心广场、居民的家),农场旁边是矿洞,还有一个可以钓鱼的湖和几块留给以后的空地;最上面是状态栏和轮转的太阳月亮。

## 第一轮为什么被否,第二轮怎么改的

第一轮画了三种构图(一屏放完、上下滑动的长卷、镇子缩成一处)。负责人一个都没有选:
**东西横平竖直地排成几行,太简单、太机械,不像一张设计过的地图**;并让参考两个种田游戏的小镇地图是怎么设计的。

毛病出在做法上:第一轮是先把屏幕切成几条(天、湖和空地、镇子、农场),再往每一条里摆东西,所以怎么摆都是一行一行的。

第二轮只学那两张地图的排法,不学画面(房子、配色、图标都是这个项目自己的)。归纳出来、用在这一稿里的:

- **先有地形,再放东西。** 那两张地图上农场、镇子、山、水各在一个方向,是被山和水分开的。这一稿两边的山坡伸进来,
  湖窝在右上的山脚,河贴着右边的山脚弯下去,把矿洞隔在对岸。负责人说的从下到上的顺序没有变。
- **路是骨架。** 镇子围着广场,路从广场弯着通向每一处;主路斜着穿到农场的门;东门过一座小桥到矿洞。
- **近的压着远的。** 立着的东西按远近排好再画,每样东西各有自己的硬边投影。
- **大小和朝向不一样。** 房子大小不同、各歪一两度;田斜着放;栅栏是一圈不规则的折线。
- **空的地方也是画出来的。** 松树、圆树、灌木、花、石头、芦苇。

没有照搬的:那两张地图把矿洞和湖都放在山里、离农场很远;这里矿洞紧挨着农场,因为挖矿和种田是每天来回最多的两处
([决策记录 0018](../../decisions/0018-town-map-as-hub.md))。

对那两张地图的了解来自公开的资料页和绘制者已有的认识;这次没能直接看到图,只读到了文字描述(各个区域在镇子的哪个方向、
河从镇子中间穿过、矿洞和湖在山里)。

## 第二轮为什么还不够,第三轮怎么改的

负责人看过第二轮:**方向对了,但不够精致。** 每个房子要更有特色;整个画面的景致、前后、错落、阴影要更细;
"比如我站在小镇前面的山头上遥看小镇,看到的会是什么样"。

第三轮照这句话改了视角和画法(第二轮的图留在 [`assets/town-map/02-redrawn-valley.png`](../../marketing/assets/town-map/02-redrawn-valley.png)):

- **一层压一层。** 远山、两边的近山、湖边的草地、镇子所在的缓坡、农场所在的平地、脚下的山头,各是一张纸;
  近的压着远的,每张纸的上沿在后面那张上留一道影子。远的浅,近的深。
- **近大远小。** 脚下的草丛最大,农场其次,镇子再小一号,湖边的小棚和远山上的松树最小;河和路近宽远窄。
- **房子有正面、侧面和屋顶**([`buildings.js`](buildings.js))。光从左上来,正面亮、侧面暗,屋顶一片亮一片暗。
  每栋各有各的样子:镇公所的钟塔和柱子,旅店的老虎窗、百叶和招牌,饭店的烟囱、露台和小旗,电影院的竖招牌和灯檐,
  商店门口的货,小屋阁楼里的草和屋脊上的风向标,家的门廊、花箱和信箱。
- **地上有影子。** 每样立着的东西在地上有一片影子,朝背着太阳或月亮的那一边倒。
- **镇名写在脚下山头的路牌上。**

为此动了两处规定,定稿时要写进美术规范:没开放的纸模型在纸白、纸白暗之外多用了一档岩石浅(画体积至少要三档);
地上的影子是一片 16% 不透明的投影色,和硬边投影是两回事。都没有新增颜色。

## 第四轮:给镇上加细节

负责人看过第三轮:**镇上的设计还是太简单,缺少装饰**,比如石板路、门前的花坛、树木、招牌、路灯、桥梁、楼梯。

第四轮加的都在 [`props.js`](props.js) 里(第三轮的图留在 [`03-hilltop-view.png`](../../marketing/assets/town-map/03-hilltop-view.png)):

- **石板路。** 镇上的路铺石板,镇外的路还是土路,一眼分得出哪里是镇子。广场铺三圈石板,正中一棵大树。
- **桥。** 主路过河换成石桥;电影院后面多了一座小拱桥,通到河对岸的空地。
- **台阶和石墙。** 镇子比河边高出一截,用一道矮石墙托着,主路在墙上开一段台阶;镇公所前面有石台和台阶。
- **路灯、树、花。** 路边的路灯,栽在树池里的行道树,苹果树,瘦高的树,树篱;每栋房子门前的花坛。
- **招牌和别的。** 路口的木路牌,镇公所门口的大告示牌,广场边的水井和长椅,柴垛,木桶。
- **居民的田。** 镇子周围和镇里空着的地方补了十几块田:刚翻过的地、一垄垄的菜、青苗、包菜、高秆的庄稼。
  它们只是景,不能点,也不表示任何状态,所以故意画得和玩家农场里的地块不一样:是一整片斜着的、一垄一垄的田,
  没有一格一格的地块,不用干土和湿土的颜色,没有水滴和星。

这些东西是景,不是地点:它们有颜色,不管旁边的房子开没开放;都不能点。没有新增颜色:石头用岩石那一组加纸白暗,
灯是一张玉米黄的纸(和矿洞里那盏一样不发光)。

代价:镇上的房子本身还是白的;小东西很小(路灯约 10pt 高,花坛约 10pt 宽),手机上是"看得出热闹",不是"看得清每一样"。

## 没开放的地方上色,不写名字

到第四轮为止,没开放的地方都画成没上色的纸模型,下面一张只写名字的小名签,理由是不把没做的画成已有的。
负责人 2026-11-22 看过之后定了:**没开放的房子不需要变灰,不在它们下面写建筑物的名字就行了。**

现在的画法:旅店、饭店、电影院、镇公所、居民的家、玩家的家、湖边的小棚和栈桥都按各自的颜色画;
它们和广场、空地下面都不再有名签。只有能进的四处(矿洞、农场、牧场、商店)有名牌。
上一版的样子留在定稿页的最后一张图里(`valley.js` 的 `closed: 'model'`)。

代价,负责人是知道的:

- **哪里能进只靠名牌来分。** 没有名牌的房子看起来和商店一样是"有的"。玩家点了它会怎样,还没有设计。
- **对外用这张图要在配文里写明现在能进的只有哪几处。** 图上有旅店、饭店、电影院,它们都还没有设计;
  不说明就是把没做的展示成已有的([内容策略](../../marketing/01-content-strategy.md#红线)的红线)。
- 这些房子的颜色是临时配的,等它们真的设计出来可能要改。

定稿时要改美术规范里"还没开放的东西不上色"那一条,并写进决策记录。

| 取舍 | 这一稿的画法 | 方案页上的其他选项 |
|---|---|---|
| 一屏还是滑动 | 一屏放完 | 上下滑动的长卷 |
| 农场那一圈画到多细 | 样子跟着存档变,名牌只有"农场"和"牧场" | 每样一个图标;一块块、一只只照实画 |
| 没开放的地方 | **负责人已定(2026-11-22):**和开放的一样上色,下面不写名字 | 纸模型(不上色,有小名签),画到第四轮都是这样;只有地基和木牌 |
| 湖和河的颜色 | 天空色。色板里已有,不是水蓝;代价是和草地的明暗只差 1.10 | 蓝绿;不上色 |
| 太阳和月亮 | 一个游戏日一个:4:00 到 16:00 太阳,16:00 到 4:00 月亮,落山就是换日 | 一个游戏日里各走一半;不走位置,只换日期前的小图标 |

状态栏沿用现在的三颗药丸(等级和经验、日期、金币),没有加东西。

## 已经想好的画法

两轮都一样:

- **哪些能进:** 现在规则里真有的只有矿洞、农场、牧场、商店。其余的(家、旅店、饭店、电影院、镇公所、中心广场、居民的家、湖边钓鱼)
  **都还没有设计**,画出来只是为了看地图装不装得下、分不分得清。
- **开放和没开放靠名牌分:** 开放的地方下面有带状况的名牌(名字 16pt,状况 11.5pt);没开放的地方上了色,但下面什么字都没有。
  这是负责人 2026-11-22 定的,取代了原来"没开放的不上色"的画法,见下面"没开放的地方上色,不写名字"一节。
- **房子是同一组纸片换颜色:** 每栋房子用到的几种纸(墙、屋顶、门、窗、招牌)是参数,纸模型把它们全换成纸白和纸白暗。开放时不用重画。
- **地图上的东西跟着存档变,不加警告图标:**
  - 田:浅色的格子是能浇水的,深色的是浇过的,三道垄的是空地,比例和真的田一样;右上角探出水滴,左上角探出收获的星。
  - 草地:到期的旧词长成草,矮、中、高三种。草地站满了就是长满了。
  - 草垛:高矮是口粮还够吃多久(4 个游戏日以上码满,2 到 3 天半垛,1 天一捆,空了只剩托板)。鸡的食槽有饲料是黄的,空了只剩木槽。
  - 牲畜饿了会趴下,头垂到地上。和作物的枯萎一样靠姿态。
  - 矿洞:有到期的旧词,洞口两边的石头上就露出矿,和矿洞里旧词的石板露着矿是同一种说法。
- **名牌只写一行,先写最需要玩家的那件事。** 牧场:有饿着的先说饿着,否则是"几株草能割 · 口粮够几天"。
  矿洞:有到期的旧词先说旧词,否则是还能答错几次。
- **栅栏用木色,不用白色:** 这张地图上白色表示还没开放。
- **路通向每一处。** 第一轮是"小路只通向开放的地方";精修稿里路是镇子的骨架,开没开放改由颜色和名牌来分。
- **路和河是剪出来的纸带,**不是描边的线。镇外的土路是木色,下面垫一条深一档的;镇上的石板路是岩石浅的路面上铺纸白和纸白暗的石板;河是天空色,两岸垫一条深草色。
- **夜里只换天的颜色**(墨绿),没有新增颜色。
- **镇名**写在脚下山头的一块木路牌上(站酷快乐体 28pt)。

## 画的时候发现的问题

都没有改规则,完整的说明在方案页最后一节。需要负责人定的已经记进[路线图的未决问题](../06-roadmap.md#未决问题)。

- **日历上的"天"有一半是夜里。** 一个游戏日 12 小时,第 3 天是白天,第 4 天就是晚上。画了月亮之后玩家会看见。
- **"口粮够 2 天"的"天"是游戏日,现实里只有 1 天。** 玩家多半按现实的天理解。牛会饿病、会死,这一处写错的后果最重。
- **牧场的名牌一行写不下全部状况。** 生病和死亡在地图上没有画。
- **牧场在地图上是一个入口还是三个**(草地、小屋、鸡舍),要和牧场画面那张卡片对齐。这里按规则画成一个。
- **湖和"蓝色只表示水"**:建议用天空色,等负责人定。
- **矿洞名牌上的旧说法**("田满了,先歇着")已经不成立,这里换了一套。
- **每画一处没开放的地方,就是向玩家多许一个诺。** 这次多了七处。对外用这些图时要写明它们还没做。
- **精修稿自己的毛病:**路的颜色很淡(木色和草地的明暗只差 1.02,靠色相认);镇上除了商店还是一片白;
  右下角挤(矿洞、名牌、词袋按钮);为了近大远小,镇上的房子小(镇公所约 75pt 宽,居民的家约 30pt),细节在手机上只看得出大概。

## 这些画面是怎么来的

- **全部用代码绘制。** JavaScript 运行时生成 SVG。没有使用图像生成模型,没有使用任何第三方图片。
- 代码由 Claude 编写,属于 AI 协助产出的内容。对外发布这些画面时,按[内容策略](../../marketing/01-content-strategy.md#红线)的要求声明。
- **它们是示意稿,不是成品。** 用途是检验构图、配色,以及手机竖屏上认不认得出。
- **画面不读取游戏数据。** 数字是手写的示意,规则以[玩法规则](../02-gameplay.md)为准。
- 不模仿任何具体的已有游戏的画面、角色、图标和配色。
