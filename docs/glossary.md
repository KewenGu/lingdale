# 术语表

文档、界面文案和代码里用同一套说法。新增概念时先在这里登记。

## 游戏概念

| 中文 | 代码里的名字 | 含义 |
|---|---|---|
| 游戏日 | `gameDay` | 游戏里的一天,现实 12 小时,在本地时间 4:00 和 16:00 切换 |
| 季节 | `season` | 28 个游戏日,现实 2 周 |
| 矿洞 | `mine` | 一个完整的学习的地方:挖新矿脉见新词,练习把不会的学会,挖旧矿脉复习。每条矿脉是一个词,挖一次答一道题 |
| 矿脉 | `Vein` | 矿里当前要挖的那个词。到期的旧词在前,然后是新词 |
| 挖矿 | `dig` | 回答当前矿脉的词 |
| 矿石 | `ore` | 在矿里答对爆出的东西。品级是掷出来的,最高到这个词的掌握度 |
| 品级 | `oreGrade`、`oreOdds` | 矿石的等级,1 到 7。记得越久的词越容易出高的;出最高那一级的机会封顶在三成 |
| 词袋 | `wordBag` | 答错的、等着被种下或练出去的词。最多比空地多装 10 个(`BAG_EXTRA`),答错的旧词不受这个限制。规则内部的东西,界面上不一定有单独的画面 |
| 答错的额度 | `mineAllowance` | 词袋还装得下几个词,也就是新词还能答错几次:空地块数 + 10 − 词袋里的词数。到 0 就不再出没见过的新词;复习不受它限制 |
| 练习 | `drill`、`drillStreak` | 词袋装满后,在矿里答词袋里的词。不出矿石、不给经验、不改掌握度。最前面的 5 个词轮着出 |
| 离开词袋 | `graduated` | 练习里连续答对 5 次,这个词离开词袋,下一个游戏日回到矿里再考一次。答对才升级,答错回词袋 |
| 没有矿脉可挖 | `MineClosed` | 没有到期的旧词,卡组里的新词挖完了,词袋里也没有词可练(`exhausted`)。田满不会让矿洞关门 |
| 小镇 | 无 | 游戏里所有地方的总称,入口是一张地图。现在有矿洞、农场、商店;核心层里没有"地点"的概念 |
| 农场、田 | `farm` | 学新词的地方:种下时见新词,浇水把不会的学会 |
| 地块 | `Plot` | 农场里的一格,同一时间只能种一株作物 |
| 候选词 | `plantCandidate` | 种下时这颗种子要带的词:先是词袋里的,词袋空了是卡组里没见过的新词。有到期的旧词没复习时不给新词 |
| 换一个 | `plantCandidate` 的 `skip`、`setAside` | 种下时不要当前的候选词。词袋里的词只是往后看一个;没见过的新词会被放到一边 |
| 放到一边 | `setAside` | 种田时换掉的新词:下一个游戏日当成旧词考一次,答对才算会,答错进词袋 |
| 牧场 | `pasture` | 复习的地方,单独一页:一块草地,一栋养牛羊的小屋,一间鸡舍 |
| 草地、牧草 | `grassStatus` | 到期的旧词长成牧草。有几个词该复习,草地上就有几株草。不用种,不占种作物的地块 |
| 割牧草 | `mowGrass` | 答一个到期的旧词。草不和词绑定,割的时候才取最早到期的那个。答对收下牧草,答错这个词进词袋 |
| 草垛 | `hay`、`sellHay`、`buyHay` | 牧草存在草垛里,按捆算。牛和羊从草垛里吃。牧草靠割;直接卖只有 2 金币一捆;也能在商店买,10 金币一捆,买来喂牛羊不赚钱,只是救急 |
| 草的高矮 | `grassSize`、`grassField`、`hayBundles` | 一株草能割下几捆:1 到 3,看这个词答对后的掌握度。记得越久的词草越高 |
| 卖牲畜 | `sellLivestock` | 养几只由玩家自己定。小的、大的各有价,病着的只能送走 |
| 牲畜 | `Animal`、`herd`、`ANIMAL_TYPES` | 牛、羊、鸡。规则一样,只有住哪、吃什么、出什么不同 |
| 小屋、鸡舍 | `houseCount` | 牛和羊住小屋、吃牧草;鸡住鸡舍、吃饲料。买价按同一处已经养了几只来涨 |
| 鸡饲料 | `feed`、`makeFeed`、`feedStatus`、`sellFeed`、`buyFeed` | 用收获的作物做,一份作物两份饲料。做一次要答一个到期的旧词,第一次就答对才做得成。也能在商店买,买 20 卖 4,买来喂鸡不赚钱 |
| 长大 | `isGrown`、`AnimalType.growthDays` | 买来或生下来的是小的,吃饱够天数才长大:牛羊 56 个游戏日(两个季节),鸡 14 个。长大了才有产出、才能再生小的 |
| 怀小的、抱窝 | `breed`、`AnimalType.gestationDays` | 玩家让一只长大的怀上(鸡是抱窝):牛羊吃饱 28 个游戏日、鸡 14 个之后生一只同种的。怀着的时候没有产出。不会自己怀上 |
| 饿着 | `animalCondition` 的 `hungry` | 上一个游戏日没吃上。不长、没有产出;吃上一顿就好 |
| 生病 | `animalCondition` 的 `sick` | 连着 14 个游戏日没吃上。不吃、不长、没有产出,要用动物药治 |
| 动物药 | `medicine`、`buyMedicine`、`cureAnimal` | 在商店买,一份治好一只病了的牲畜。只治病不管饱 |
| 牲畜死亡 | `SICK_DAYS_TO_DIE` | 病了 30 个游戏日还没治。和作物的死亡不是一回事 |
| 口粮 | `rationOf` | 一只牲畜一个游戏日吃的:牛 6 捆牧草,羊 4 捆,鸡 2 份饲料;没长大的吃一半。不够吃时最饿的先吃 |
| 牛奶、羊毛、鸡蛋 | `goods`、`sellGoods`、`AnimalType.yieldDays` | 长大的牛和鸡每吃饱一个游戏日出一份,羊每吃饱三个游戏日出一份羊毛。可以卖,以后可以做料理 |
| 结算牧场 | `settlePasture` | 把所有牲畜从上次到现在的日子一天天过完:吃、长大、产出、挨饿、生病、死亡。玩家没来的日子也算 |
| 种子 | `seeds` | 在商店买,按品种分三种。决定作物的品种和题型,不决定种的是哪个词 |
| 种子种类、品种 | `CropKind` | 一种种子的属性:题型、价格、售价倍率、解锁等级 |
| 兜底种子 | `claimReliefSeed` | 词袋里有词要种、却没种子、买不起、也没东西可卖时,商店送的一颗基础种子。只防卡死,不是开局的本钱 |
| 作物 | `Crop` | 地块上正在生长的一株植物,对应一个词 |
| 作物种类 | `CropType` | 某个季节里某种题型对应的作物,如萝卜、番茄 |
| 播种 | `plant` | 用一颗种子把词袋里的一个词种到空地上 |
| 浇水 | `answer`、`water` | 回答这株作物的词;每个游戏日一次 |
| 浇一轮水 | `thirstyCards` + `ReviewSession` | 把所有能浇的作物连着浇一遍 |
| 生长形态 | `GROWTH_STAGES`、`cropGrowth` | 种子、发芽、幼苗、成株、开花 |
| 品质、星级 | `stars`、`cropStars` | 1 到 5 星,这一轮每答错一次扣一星 |
| 健康状态 | `CropHealth` | 健康、不生长、枯萎 |
| 不生长 | `stunted` | 上一次浇水答错了 |
| 枯萎 | `wilted` | 连续答错两次 |
| 死亡 | `died` | 连续答错三次,作物消失,种子白费 |
| 收获 | `Harvest` | 浇对 5 次后作物进入库存 |
| 库存 | `produce`、`ore`、`hay`、`goods` | 还没卖的作物、矿石、牧草、牛奶、羊毛和鸡蛋。界面上在商店的"卖东西"一页 |
| 金币 | `coins` | 来自卖矿石、作物、牧草、牛奶、羊毛和鸡蛋,用来买种子、解锁地块、买牲畜和动物药 |
| 经验 | `xp` | 所有学习活动的汇总 |
| 等级 | `level` | 由累计经验算出,解锁种子和小镇内容 |
| 解锁内容 | `Milestone` | 到达某个等级时开放的东西 |

## 学习概念

| 中文 | 代码里的名字 | 含义 |
|---|---|---|
| 卡片 | `Card` | 一个要记住的知识点,有正面和背面 |
| 卡组 | `Deck` | 一组有顺序的卡片,比如四级词汇 |
| 干扰项 | 无 | 选择题里错的那三个选项。卡片带词性时只取同词性、意思不重合的词 |
| 短释义 | `back` | 卡片背面:主词性加一到两条不超过 8 个字的释义。正式词库的短释义存在 `data/cet4-glosses.txt` |
| 蒙对率 | `guessRate`(在 `sim/`) | 不认识这个词的人答对选择题的比例。四选一的底线是 25% |
| 词 | `cardId` | 文档里说"词"时指一张卡片 |
| 新词 | `source: 'new'` | 第一次在矿里见到的词 |
| 旧词 | `source: 'review'` | 以前见过、休息结束后回到矿里的词 |
| 生词 | 无 | 口语说法,指在矿里答错、要去种的词 |
| 摸底 | 无 | 新词先在矿里答一道题,会的就不用种 |
| 掌握度 | `mastery` | 0 到 7。决定矿石的品级和休息多久 |
| 一轮 | cycle | 一个词从被种下到收获或死亡的过程 |
| 休息 | `rest` | 答对、收获或死亡之后,这个词暂时不会出现的那段时间 |
| 到期的旧词 | `dueVeins` | 休息结束、该复习的词。在矿里是旧矿脉,在牧场是草地上的草,做鸡饲料时考的也是它;有它们在,矿洞和农场都不给新词 |
| 休息中的旧词 | `restingVeins` | 还没到期的旧词,以及各在什么时候回到矿里 |
| 积压 | backlog | 到期了但还没挖的旧词数量 |
| 题型 | `QuestionType` | 看词选义、看义选词、拼写 |
| 看词选义 | `choice` | 给单词,从四个释义里选 |
| 看义选词 | `reverse` | 给释义,从四个单词里选 |
| 拼写 | `spell` | 给释义,输入单词 |
| 评分 | `Grade` | `good` 答对,`again` 答错,`hard` 不算对也不算错 |
| 首次作答 | `first` | 一次浇水里对这个词的第一次回答,只有它计入结果 |
| 重复练习 | `requeued` | 浇水答错后当场再答,直到答对,不计入结果。和矿里的"练习"不是一回事 |
| 作答日志 | `ReviewLog` | 每次首次作答的记录,包括在矿里还是田里 |

## 画面概念

定义和画法见[美术规范](design/07-art-direction.md)。这些只是画面上的说法,代码里没有对应的名字。

| 中文 | 含义 |
|---|---|
| 干土 | 浅色的地块,表示这株作物现在能浇水 |
| 湿土 | 深色的地块,表示今天浇过了,或今天刚种下 |
| 水滴标记 | 地块右上角的蓝色水滴,和干土一起表示能浇水 |
| 收获标记 | 地块左上角的黄色四角星,表示下一次浇对就收获 |
| 星带 | 地块下沿的一排五个点,表示品质 |
| 计数角标 | 按钮或矿石右上角的玉米黄圆片,里面的数字只表示"有几个" |
| 岩层 | 矿洞一屏的构图:整屏是矿壁,四个选项是四条横着的石板 |
| 词牌 | 挂在矿洞木梁下的一张纸,写着当前矿脉的词 |
| 石板 | 矿洞里的一个选项。点哪条,镐就落在哪条上 |
| 垫片 | 矿石下面那块岩石深色的石片。矿石在界面里总是垫着它 |
| 形状阶梯 | 矿石品级的画法:圆的是粗矿,方的是贵金属,尖的是宝石,一级比一级大 |
| 四叶草 | 爆出的矿石旁边的记号,表示这次运气好:爆出了这条矿脉能出的最高一级 |
| 还能答错几次 | 界面上对答错的额度的叫法。画成一块缩小的空地加一个数 |
| 歇着 | 矿洞因为田满而关门时画面上的说法。不说"关闭""锁定" |
| 小镇地图 | 所有地方的总入口。每个地点下面的名牌写着它现在的状况 |
| 名牌 | 小镇地图上地点下面的纸片:名字一行,状况一行 |
| 路牌 | 底部那块直达另一处的按钮,只连农场和矿洞。上面贴着一块指向那边的木牌 |
| 纸模型 | 小镇地图上还没开放的地方:只有形状,没有上色 |
| 示意稿 | 用来检验方向的画面,不是成品美术。对外使用时要写明 |

## 已经废弃的说法

这些词出现在早期讨论和提交历史里,现在的设计中已经没有了。不要再使用。

| 说法 | 当时的含义 | 被什么取代 |
|---|---|---|
| 谷仓 | 学稳的词所在的长期复习池 | 掌握度和休息 |
| 害虫 | 答错后离开作物、需要单独清理的词 | 不生长、枯萎、死亡 |
| 种子制造机、回炉 | 把低星作物变回同一个词的种子 | 种子不再绑定单词,低星只是降掌握度 |
| 补种 | 作物死亡后要用新种子重种同一个词 | 这个词休息后自然回来 |
| 毕业 | 词从田里进入谷仓 | 收获 |
| 成熟 | 作物里有词到期 | 需要浇水 |
| 自评题、回忆题 | 看词回忆后自己点记得或忘了 | 三种客观题型 |
| 仓库 | 农场底部一个查看库存的按钮 | 并进了商店的"卖东西"一页,见决策记录 0018 |
| 品级带 | 矿石下面一排 7 个点,表示品级 | 只在方案比较时画过,没有采用;品级靠形状阶梯 |
| 通用种子、系统分配单词 | 种子不绑定单词,种下时由系统决定长成哪个词 | 词来自矿洞的词袋,种子只决定品种 |
| 复习作物 | 旧词休息结束后重新种下,浇 3、2、1 次水 | 旧词在矿里复习,一次一道题 |
| 每日免费种子、种子店限量 | 每个游戏日领免费种子、限量购买 | 种子随时可买,开局不送,只有兜底种子 |
