# 术语表

文档、界面文案和代码里用同一套说法。新增概念时先在这里登记。

## 游戏概念

| 中文 | 代码里的名字 | 含义 |
|---|---|---|
| 游戏日 | `gameDay` | 游戏里的一天,现实 12 小时,在本地时间 4:00 和 16:00 切换 |
| 季节 | `season` | 28 个游戏日,现实 2 周 |
| 矿洞 | `mine` | 筛选和复习的地方。每条矿脉是一个词,挖一次答一道题 |
| 矿脉 | `Vein` | 矿里当前要挖的那个词。到期的旧词在前,然后是新词 |
| 挖矿 | `dig` | 回答当前矿脉的词 |
| 矿石 | `ore` | 在矿里答对爆出的东西,品级等于这个词的掌握度 |
| 品级 | `oreGrade` | 矿石的等级,1 到 7 |
| 词袋 | `wordBag` | 在矿里答错、等着被种下的词。田满时答错的旧词、再考还是答错的生词在这里排队,所以可以比空地多 |
| 答错的额度 | `mineAllowance` | 新词还能答错几次:田里的空位,加上还能再攒的生词数。到 0 就不再出新词;复习不受它限制 |
| 留在矿里再考 | `deferred` | 田满时答错的新词没地方种,不进词袋,下一个游戏日在矿里再考一次。答对就不用种,答错才进词袋 |
| 没地方种的生词 | `waitingWords`、`WAITING_CAP` | 在矿里等着再考的,加上词袋里比空地多出来的。最多 10 个,到了就不再出新词 |
| 矿洞关门 | `MineClosed` | 挖不了:额度用完、到期的旧词也挖完了(`no_room`),或没有矿脉可挖(`exhausted`) |
| 小镇 | 无 | 游戏里所有地方的总称,入口是一张地图。现在有矿洞、农场、商店;核心层里没有"地点"的概念 |
| 地块 | `Plot` | 农场里的一格,同一时间只能种一株作物 |
| 种子 | `seeds` | 在商店买,按品种分三种。决定作物的品种和题型,不决定种的是哪个词 |
| 种子种类、品种 | `CropKind` | 一种种子的属性:题型、价格、售价倍率、解锁等级 |
| 兜底种子 | `claimReliefSeed` | 玩家有词要种却没种子、买不起、也没东西可卖时,商店送的一颗基础种子 |
| 作物 | `Crop` | 地块上正在生长的一株植物,对应一个词 |
| 作物种类 | `CropType` | 某个季节里某种题型对应的作物,如萝卜、番茄 |
| 播种 | `plant` | 用一颗种子把词袋里的一个词种到空地上 |
| 浇水 | `answer`、`water` | 回答这株作物的词;每个游戏日一次 |
| 浇一轮水 | `thirstyCards` + `ReviewSession` | 把所有能浇的作物连着浇一遍 |
| 生长形态 | `GROWTH_STAGES`、`cropGrowth` | 种子、发芽、幼苗、成株、开花 |
| 品质、星级 | `stars`、`cropStars` | 1 到 5 星,这一轮每答错一次扣一星 |
| 健康状态 | `CropHealth` | 健康、不生长、枯萎 |
| 不生长 | `stunted` | 上一次浇水答错了 |
| 枯萎 | `wilted` | 连续答错两次 |
| 死亡 | `died` | 连续答错三次,作物消失,种子白费 |
| 收获 | `Harvest` | 浇对 5 次后作物进入库存 |
| 库存 | `produce`、`ore` | 收获后还没卖的作物,和挖到还没卖的矿石。界面上在商店的"卖东西"一页 |
| 金币 | `coins` | 来自卖矿石和卖作物,用来买种子和解锁地块 |
| 经验 | `xp` | 所有学习活动的汇总 |
| 等级 | `level` | 由累计经验算出,解锁种子和小镇内容 |
| 解锁内容 | `Milestone` | 到达某个等级时开放的东西 |

## 学习概念

| 中文 | 代码里的名字 | 含义 |
|---|---|---|
| 卡片 | `Card` | 一个要记住的知识点,有正面和背面 |
| 卡组 | `Deck` | 一组有顺序的卡片,比如四级词汇 |
| 词 | `cardId` | 文档里说"词"时指一张卡片 |
| 新词 | `source: 'new'` | 第一次在矿里见到的词 |
| 旧词 | `source: 'review'` | 以前见过、休息结束后回到矿里的词 |
| 生词 | 无 | 口语说法,指在矿里答错、要去种的词 |
| 摸底 | 无 | 新词先在矿里答一道题,会的就不用种 |
| 掌握度 | `mastery` | 0 到 7。决定矿石的品级和休息多久 |
| 一轮 | cycle | 一个词从被种下到收获或死亡的过程 |
| 休息 | `rest` | 答对、收获或死亡之后,这个词暂时不会出现的那段时间 |
| 到期的旧词 | `dueVeins` | 休息结束、重新出现在矿里的词 |
| 休息中的旧词 | `restingVeins` | 还没到期的旧词,以及各在什么时候回到矿里 |
| 积压 | backlog | 到期了但还没挖的旧词数量 |
| 题型 | `QuestionType` | 看词选义、看义选词、拼写 |
| 看词选义 | `choice` | 给单词,从四个释义里选 |
| 看义选词 | `reverse` | 给释义,从四个单词里选 |
| 拼写 | `spell` | 给释义,输入单词 |
| 评分 | `Grade` | `good` 答对,`again` 答错,`hard` 不算对也不算错 |
| 首次作答 | `first` | 一次浇水里对这个词的第一次回答,只有它计入结果 |
| 重复练习 | `requeued` | 浇水答错后当场再答,直到答对,不计入结果。矿里没有 |
| 作答日志 | `ReviewLog` | 每次首次作答的记录,包括在矿里还是田里 |

## 画面概念

定义和画法见[美术规范](design/07-art-direction.md)。这些只是画面上的说法,代码里没有对应的名字。

| 中文 | 含义 |
|---|---|
| 干土 | 浅色的地块,表示这株作物现在能浇水 |
| 湿土 | 深色的地块,表示今天浇过了,或今天刚种下 |
| 水滴标记 | 地块右上角的蓝色水滴,和干土一起表示能浇水 |
| 收获标记 | 地块左上角的黄色四角星,表示下一次浇对就收获 |
| 星带 | 地块下沿的一排五个点,表示品质 |
| 计数角标 | 按钮或矿石右上角的玉米黄圆片,里面的数字只表示"有几个" |
| 岩层 | 矿洞一屏的构图:整屏是矿壁,四个选项是四条横着的石板 |
| 词牌 | 挂在矿洞木梁下的一张纸,写着当前矿脉的词 |
| 石板 | 矿洞里的一个选项。点哪条,镐就落在哪条上 |
| 垫片 | 矿石下面那块岩石深色的石片。矿石在界面里总是垫着它 |
| 形状阶梯 | 矿石品级的画法:圆的是粗矿,方的是贵金属,尖的是宝石,一级比一级大 |
| 四叶草 | 爆出的矿石旁边的记号,表示这次运气好、矿石多升了一级 |
| 还能答错几次 | 界面上对答错的额度的叫法。画成一块缩小的空地加一个数 |
| 歇着 | 矿洞因为田满而关门时画面上的说法。不说"关闭""锁定" |
| 小镇地图 | 所有地方的总入口。每个地点下面的名牌写着它现在的状况 |
| 名牌 | 小镇地图上地点下面的纸片:名字一行,状况一行 |
| 路牌 | 底部那块直达另一处的按钮,只连农场和矿洞。上面贴着一块指向那边的木牌 |
| 纸模型 | 小镇地图上还没开放的地方:只有形状,没有上色 |
| 示意稿 | 用来检验方向的画面,不是成品美术。对外使用时要写明 |

## 已经废弃的说法

这些词出现在早期讨论和提交历史里,现在的设计中已经没有了。不要再使用。

| 说法 | 当时的含义 | 被什么取代 |
|---|---|---|
| 谷仓 | 学稳的词所在的长期复习池 | 掌握度和休息 |
| 害虫 | 答错后离开作物、需要单独清理的词 | 不生长、枯萎、死亡 |
| 种子制造机、回炉 | 把低星作物变回同一个词的种子 | 种子不再绑定单词,低星只是降掌握度 |
| 补种 | 作物死亡后要用新种子重种同一个词 | 这个词休息后自然回来 |
| 毕业 | 词从田里进入谷仓 | 收获 |
| 成熟 | 作物里有词到期 | 需要浇水 |
| 自评题、回忆题 | 看词回忆后自己点记得或忘了 | 三种客观题型 |
| 仓库 | 农场底部一个查看库存的按钮 | 并进了商店的"卖东西"一页,见决策记录 0018 |
| 品级带 | 矿石下面一排 7 个点,表示品级 | 只在方案比较时画过,没有采用;品级靠形状阶梯 |
| 通用种子、系统分配单词 | 种子不绑定单词,种下时由系统决定长成哪个词 | 词来自矿洞的词袋,种子只决定品种 |
| 复习作物 | 旧词休息结束后重新种下,浇 3、2、1 次水 | 旧词在矿里复习,一次一道题 |
| 每日免费种子、种子店限量 | 每个游戏日领免费种子、限量购买 | 种子随时可买,开局不送,只有兜底种子 |
