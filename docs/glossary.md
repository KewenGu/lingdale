# 术语表

文档、界面文案和代码里用同一套说法。新增概念时先在这里登记。

## 游戏概念

| 中文 | 代码里的名字 | 含义 |
|---|---|---|
| 游戏日 | `gameDay` | 游戏里的一天,现实 12 小时,在本地时间 4:00 和 16:00 切换 |
| 季节 | `season` | 28 个游戏日,现实 2 周 |
| 地块 | `Plot` | 农场里的一格,同一时间只能种一株作物 |
| 种子 | `seeds` | 按题型分三种,不绑定单词 |
| 种子种类 | `SeedKind` | 一种种子的属性:题型、价格、售价倍率、解锁等级 |
| 作物 | `Crop` | 地块上正在生长的一株植物,对应一个词 |
| 作物种类 | `CropType` | 某个季节里某种题型对应的作物,如萝卜、番茄 |
| 播种 | `plant` | 在空地上种下一颗种子,系统为它分配一个词 |
| 浇水 | `answer`、`water` | 回答这株作物的词;每个游戏日一次 |
| 浇一轮水 | `thirstyCards` + `ReviewSession` | 把所有能浇的作物连着浇一遍 |
| 生长形态 | `GROWTH_STAGES`、`cropGrowth` | 种子、发芽、幼苗、成株、开花 |
| 品质、星级 | `stars`、`cropStars` | 1 到 5 星,这一轮每答错一次扣一星 |
| 健康状态 | `CropHealth` | 健康、不生长、枯萎 |
| 不生长 | `stunted` | 上一次浇水答错了 |
| 枯萎 | `wilted` | 连续答错两次 |
| 死亡 | `died` | 连续答错三次,作物消失,种子白费 |
| 收获 | `Harvest` | 浇对足够次数后作物进入库存 |
| 库存 | `produce` | 收获后还没卖的作物 |
| 金币 | `coins` | 只来自卖作物,用来买种子和解锁地块 |
| 经验 | `xp` | 所有学习活动的汇总 |
| 等级 | `level` | 由累计经验算出,解锁种子和小镇内容 |
| 解锁内容 | `Milestone` | 到达某个等级时开放的东西 |

## 学习概念

| 中文 | 代码里的名字 | 含义 |
|---|---|---|
| 卡片 | `Card` | 一个要记住的知识点,有正面和背面 |
| 卡组 | `Deck` | 一组有顺序的卡片,比如四级词汇 |
| 词 | `cardId` | 文档里说"词"时指一张卡片 |
| 新词 | `source: 'new'` | 第一次被种下的词 |
| 旧词 | `source: 'review'` | 以前种过、休息结束后再次被种下的词 |
| 掌握度 | `mastery` | 0 到 7。决定回来时要浇几次水、收获后休息多久 |
| 一轮 | cycle | 一个词从被种下到收获或死亡的过程 |
| 休息 | `rest` | 一轮结束后,这个词暂时不会出现的那段时间 |
| 该复习的词 | `dueWords` | 休息结束、等着被再次种下的旧词 |
| 积压 | backlog | 该复习但还没种下的词的数量 |
| 题型 | `QuestionType` | 看词选义、看义选词、拼写 |
| 看词选义 | `choice` | 给单词,从四个释义里选 |
| 看义选词 | `reverse` | 给释义,从四个单词里选 |
| 拼写 | `spell` | 给释义,输入单词 |
| 评分 | `Grade` | `good` 答对,`again` 答错,`hard` 不算对也不算错 |
| 首次作答 | `first` | 一次浇水里对这个词的第一次回答,只有它计入结果 |
| 重复练习 | `requeued` | 答错后当场再答,直到答对,不计入结果 |
| 作答日志 | `ReviewLog` | 每次首次作答的记录 |

## 画面概念

定义和画法见[美术规范](design/07-art-direction.md)。这些只是画面上的说法,代码里没有对应的名字。

| 中文 | 含义 |
|---|---|
| 干土 | 浅色的地块,表示这株作物现在能浇水 |
| 湿土 | 深色的地块,表示今天浇过了,或今天刚种下 |
| 水滴标记 | 地块右上角的蓝色水滴,和干土一起表示能浇水 |
| 收获标记 | 地块左上角的黄色四角星,表示下一次浇对就收获 |
| 星带 | 地块下沿的一排五个点,表示品质 |
| 示意稿 | 用来检验方向的画面,不是成品美术。对外使用时要写明 |

## 已经废弃的说法

这些词出现在早期讨论和提交历史里,现在的设计中已经没有了。不要再使用。

| 说法 | 当时的含义 | 被什么取代 |
|---|---|---|
| 谷仓 | 学稳的词所在的长期复习池 | 掌握度和休息 |
| 害虫 | 答错后离开作物、需要单独清理的词 | 不生长、枯萎、死亡 |
| 种子制造机、回炉 | 把低星作物变回同一个词的种子 | 种子不再绑定单词,低星只是降掌握度 |
| 补种 | 作物死亡后要用新种子重种同一个词 | 这个词休息后自然回来 |
| 毕业 | 词从田里进入谷仓 | 收获 |
| 成熟 | 作物里有词到期 | 需要浇水 |
| 自评题、回忆题 | 看词回忆后自己点记得或忘了 | 三种客观题型 |
