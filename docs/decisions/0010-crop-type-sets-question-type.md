# 0010 作物种类决定题型,全部用客观题

- 日期:2026-11-16
- 状态:生效
- 决定者:项目负责人(作物对应题型),题型的具体选择由开发时确定

## 背景

之前所有作物都一样。题型按生长阶段自动切换:早期是选择题,之后是"看词回忆,然后自己点记得或忘了"的自评题。

答错有了扣星和死亡的代价之后,自评题出了问题:玩家有很强的动机直接点"记得"。

## 决定

- 作物分种类,不同种类对应不同题型。玩家选种哪种作物,就选了这株作物的题型。
- 目前三种题型,由易到难:看词选义、看义选词、拼写。
- 越难的种子越贵,长出的作物售价倍率越高,并且需要更高的等级才能解锁。
- 全部题型都能自动判对错。去掉自评题。

## 理由

- 题型由作物决定,让玩家对难度有了选择,也让"种什么"成为一个真正的决定。
- 更难的题型对应更深的学习(从再认到回忆),用更高的售价来鼓励。
- 有代价的地方必须客观判分,否则规则会被绕过,星级和掌握度也就失去了意义。
- 等级解锁高级种子,让升级有了实际的用处。

## 被否决的方案

- **题型按生长阶段自动切换。** 玩家没有选择,而且后期阶段依赖自评。
- **保留自评题。** 见背景。

## 后果

- 高级作物的价格倍率(1.5 倍、2.5 倍)和解锁等级(4 级、8 级)是估的,需要真人试玩来调。
- 玩家可能一直只种最容易的作物。价格倍率是否足以引导他们往上走,还不知道。
- 选择题可以猜。全程只种基础作物的玩家,掌握度会被高估。
- 拼写题在手机上输入较慢,界面需要专门设计。
- 听力题型需要音频,还没有做。
