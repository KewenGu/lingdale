# 0026 第一个正式词库:四级常用 1000 词;干扰项只取同词性、不近义的

- 日期:2026-11-22
- 状态:生效
- 决定者:项目负责人(先做四级、先做一千词、同时做一个能答题的页面)。
  开发时补的细节见"决定"的后半,需要负责人确认

## 背景

到这一步为止只有 30 个词的示例卡组,出题时干扰项在整个卡组里随机抽。美术还在探索,负责人决定趁这段时间
把"答题的数据和答题的引擎"先做出来:

> 四级,先做一千词,答题页也做。

绕不开的事实:

- 学习的真实性是底线。释义错了,玩家学到的就是错的;选择题能蒙对,不会的词就被当成会的。
- 开源词典 ECDICT 是 MIT 许可,可以商用,带四级标签和词频。但它的中文释义很长、几种词性并列,
  记"各词性用得多不多"的那一栏对这批词是空的。
- 30 个词的卡组里看不出来的问题,1000 个词时会出现:四个选项里词性各不相同,只要认得出题面是个形容词,就能排除掉名词和动词。

## 决定

**负责人的决定:**

- 第一个正式词库是大学英语四级,先做 1000 个词。
- 做一个不带美术的答题页,接上现有的规则,现在就能每天背。

**开发时补的细节:**

- **选词:** 词典里标了四级、又没标中考的词,按词频取前 1000 个。中考的 695 个词对准备四级的人太基础,先不放。
- **短释义由 AI 写,不从词典里按规则截。** 每个词定一个主词性、一到两条不超过 8 个字的释义,存在
  `data/cet4-glosses.txt`。词典只用来选词、排序、给音标,以及核对:词性对不上的 0 个,释义措辞对不上的 113 个。
- **干扰项只取同词性、意思不重合的词。** 卡片多了两个可选的字段:`pos`(词性)和 `alt`(这个词的全部释义,不显示)。
  出选择题时,干扰项先从同词性的卡片里挑;两张卡片的释义有一条相同或互相包含,就不互相当干扰项。
  同词性的不够(介词、数词)再放宽到别的词性。没有这两个字段的卡组照旧随机抽。
- **用数字盯着蒙对率。** `npm run guess` 让一个"不认识任何词、只会看后缀猜词性"的答题者把整个卡组答一遍。
  这个词库上:随机干扰项时他能蒙对 35.9%(看词选义)和 40.4%(看义选词);同词性的干扰项下是 25.0% 和 25.0%,
  也就是四选一的底线。这是算出来的,不是真人数据。
- **答题页只接了矿洞。** 矿洞一条路就能把见新词、学会、长期复习做完(设计支柱第 6 条),接它最少的界面就能开始背。
  农场、牧场、商店没有接。页面答完每题可以标记"释义不准""有两个选项都对""音标不对"。

## 被否决的方案

- **从词典里按规则截释义**(取第一个词性的第一条)。试过:词典里词性的先后不代表常用程度,
  reject、issue、scale 这样的词会挑错,一千个词里错得太多,而且错的是玩家要记住的东西。
- **干扰项继续随机抽。** 省事,但蒙对率从 25% 涨到 36% 到 40%。模拟里"蒙对的词晚几天才筛出来"的结论是按 25% 算的。
- **专门挑形近或义近的词当干扰项。** 区分度更高,但没有可靠的数据判断哪些词"近而不同":近义词放进同一题,
  可能两个选项都算对。先做到"靠词性排除不了",难的干扰项等有真人答题记录再说。
- **把中考的词也放进来。** 词更全,但前一千个里大半会是 time、people 这样的词,准备四级的人每天答的都是会的。
  代价是词库不"全":以后要不要补,要负责人定。
- **把词典放进仓库。** 66MB,而且重新生成只在改词库时才需要。仓库里只留生成脚本、短释义和生成的卡组。

## 后果

- 有了能真的用来背的词库和页面,可以开始攒真人的答题记录:模拟里最没把握的几个假设
  (本来认识多少词、看过一次答案能记多久)第一次有数据可对。
- **短释义没有人逐个校对过。** 这是现在最大的内容风险。页面上的标记是补救的办法,不是校对。
- 音标来自词典的老写法,不可靠,上线前要换来源。没有例句和发音。
- 蒙对率回到 25% 只说明"靠词性排除不了"。靠释义的长短、用字的生僻程度还能不能猜,没有量过。
- 练习页是一份独立的界面代码(`web/`),不是 Cocos 工程的一部分。它证明了核心层不改一行就能接界面,
  但里面的界面做法不会原样搬进游戏。
