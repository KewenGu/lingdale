# 0001 以语言学习为里、游戏为表,对手是背单词应用

- 日期:2026-11-15
- 状态:生效
- 决定者:项目负责人

## 背景

想做一款把学习和种田养成结合起来的游戏。最大的担心是两头不讨好:
想学习的人觉得效率低,想玩游戏的人觉得题目太多。

这类产品最常见的失败方式是把题目做成玩游戏要交的过路费。玩家想跳过题,学习者嫌游戏碍事。

## 决定

- 产品的目标是让用户爱不释手。**学习是里,游戏是表。**
- 目标用户是本来就想学、但坚持不下来的人。
- 对手是背单词应用,不是种田游戏。
- 学习动作必须是游戏动作本身。

## 理由

- 纯粹想玩游戏的人永远会去玩真正的种田游戏,这群人争取不来,也不必争取。
- 多数学习者的瓶颈不是每分钟背几个词,而是第二、三周就放弃了。产品要解决的是坚持。
- 这样定位之后,对游戏性的要求从"和星露谷一样好玩"变成"明显比背单词应用好玩",后者是可以达到的。
- 种田游戏"每天回来照料"的节奏和间隔复习"每天回忆到期的内容"的节奏天然一致。

## 被否决的方案

- **每做一个游戏动作就答一道题**(每浇一次水、每挖一次矿都背一个单词)。这是过路费模式。
- **一开始就支持各种学科**(比如初中各科题目)。单词是原子化的、几秒一题、适合间隔复习;
  数学题一道要几分钟,需要完全不同的设计。先只做背单词。

## 后果

- 所有设计都要过"学习动作是不是游戏动作本身"这一关。
- 第一批用户限定为学英语的中文使用者。
- 需要用原型自测来验证这个方向,标准见[愿景](../design/01-vision.md#怎样算成功)。
