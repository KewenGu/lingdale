# 0014 英文名改为 Lingdale

- 日期:2026-11-18
- 状态:生效。取代 [0011](0011-name.md) 中的英文名部分
- 决定者:项目负责人

## 背景

[0011](0011-name.md) 定的英文名是 Lingu Town。对外发布之前做名称查重,公开渠道发现
"Lingu" 在语言学习领域有在先使用者:挪威语言培训公司 Lingu AS 有一款同名的语言学习应用,
自述 2015 年起 "Lingu" 是语言教育领域的受保护商标,并且正在进入国际英语培训市场。
详见[名称查重](../marketing/03-name-check.md)。

## 决定

- 英文名:**Lingdale**,不加 Town。
- 中文名不变:**灵谷小镇**。
- 仓库名改为 `lingdale`。

## 理由

- 和中文名一一对应:Ling 对"灵",dale(山谷)对"谷"。
- 英语里以 -dale 结尾的常是镇名,如 Riverdale、Rosedale,所以 Lingdale 本身就读作一个小镇的名字,
  相当于"灵谷小镇",不需要再加 Town。
- Ling 仍然带一点 lingua 的联想,只是比 Lingu 弱。
- 公开渠道没有发现使用 Lingdale 的产品或公司。

## 被否决的方案

第二轮查重的候选和结果都记在[名称查重](../marketing/03-name-check.md)里。主要的几个:

| 候选 | 否决原因 |
|---|---|
| Lingu Town | Lingu AS 在语言教育领域的在先使用 |
| Lingoo | 读音和"灵谷"最接近,但 LINGOO 是伦敦一家语言交换平台的有效美国注册商标,另有一款同名语言学习应用 |
| Linggoo | 没有在用的产品,但 .com 和 .app 今年同一天被注册;读音和 LINGOO、Linggo 几乎相同 |
| Lingvale、Wordvale | 同名网站今年刚注册,分别是在线英语课程和词汇学习应用 |
| Lexivale | 可用,但和"灵谷"的读音无关,中英文名不再是一对 |
| Linggu Valley | 可用,但和灵谷寺、灵谷洞同名,搜索会被景点占满 |

## 后果

- **商标局的正式检索还没做。** 公开渠道查不到已注册但没在用的商标。对外发布之前,要在国家知识产权局、
  WIPO、美国专利商标局按软件、游戏、教育类别检索 Lingdale 和灵谷小镇。
- lingdale.com 在 2016 年已被注册,目前是空页面;lingdale.app 尚未注册。检索通过后应尽快注册可用的域名。
- 应用商店里只靠 "Lingdale" 一个词看不出是什么产品,上架时需要副标题说明,比如背单词、种田。
- 0011 里关于中文名"灵谷小镇"的理由和后果(修仙联想、灵谷寺)仍然成立。
