# 0027 牧场一屏上不写"够吃几顿",见底时用一个感叹号

- 日期:2026-11-21
- 状态:生效。修改 [0026](0026-pasture-screens-art.md) 里"牧场一屏上的字"那一条,并给美术规范的"没有感叹号"开了一个例外
- 决定者:项目负责人(牧场一屏上不要这些文字、点开才看、见底时加感叹号)。感叹号的样子和"不够两顿"这条线是绘制时定的,需要负责人确认

## 背景

[0026](0026-pasture-screens-art.md) 里负责人第一次看牧场一屏时说字太多。改了一稿:草垛和饲料桶下面各留一张两小行的牌子("够吃 3 顿""到后天早上"),
牲畜饿着或者病了时栅栏上多一句话("病了的还能等 15 天")。负责人看过之后的意见:

> 我觉得牧场的页面上要不不要够吃几顿饿了几天这些文字了,这些都可以通过点击动物小屋鸡舍草垛饲料桶看到,
> 在草垛和饲料桶见底的时候加一个感叹号 catch 用户 attention 就可以。

绕不开的事实:

- 美术规范的"不做什么"写着:不吓人,不催人,没有骷髅、裂痕、黑色的枯枝、红色警告、**感叹号**、倒计时。
- 牲畜会饿、会病、会死([0023](0023-cows-grow-starve-and-die.md));[Cocos 接入](../dev/cocos-integration.md#牧场)要求"要让玩家一眼看出够不够吃","牛快死的时候要提前说"。
- 草垛和饲料桶本来就画成几种大小,牲畜的饿和病本来就有姿态和标记(空碗、药瓶)。

## 决定

- **牧场一屏上不写存粮和牲畜的状况。** 去掉草垛和饲料桶下面的牌子,去掉栅栏上的纸条。平常这一屏除了顶部和底部没有字。
- **准话在点开之后:**
  - 点草垛:一张卡片,写着有几捆、够吃几顿、吃到什么时候、小屋一顿吃多少、草地上的草割完能添多少。这张卡片是新画的。
  - 点饲料桶:做饲料那张纸,标题旁边多一行"饲料 8 份 · 够吃 1 顿,到明天早上"。
  - 点小屋、鸡舍:那张纸的第一行是同一句话;每只牲畜饿了几天、病了几天、还能等几天在每一行里。
- **草垛或饲料桶见底时,右上角探出一个感叹号。**

**绘制时定的,需要负责人确认:**

- **"见底"的线是不够吃两顿**,也就是撑不过现实的一天;空了也算。没有要喂的牲畜(一只没养,或者都病着)时不出。
- **感叹号是墨绿色的,画在纸白的圆片上**,和水滴、空碗、药瓶是同一种探出来的标记。不用红色。只用在草垛和饲料桶上。
- 见底时草垛的卡片上才多出"去商店救急"。
- 草都割完时,底部"割一轮草"的位置换成一张写着"没有草可割"的纸片(上一稿这里放的是草垛和够吃几顿)。

## 理由

- **负责人的理由:** 这些话点一下就看得到,不必一直摆在屏上;真正需要叫住玩家的只有"快没得吃了"这一件事,一个感叹号就够。
- **画着的东西不用再写一遍。** 草垛的大小、牲畜垂头和卧倒、空碗和药瓶已经在说同样的事。字拿掉之后,这一屏和农场一样,扫一眼看的是画。
- **感叹号放在草垛上,而不是牲畜上:** 牲畜头上已经有空碗和药瓶;存粮是原因,牲畜的状况是结果。见底时它比牲畜挨饿早一步出现。
- **为什么不用红色:** 规范里"红色是东西本身的颜色,不当警告色"这一条没有动。墨绿色的感叹号在纸白圆片上对比 10.85,够醒目。
- **为什么线定在两顿:** 一天两顿。不够两顿,就是今天不割草、明天这个时候就有牲畜吃不上。线定得再早(比如三四顿),感叹号会经常挂着,就不叫人了。

## 被否决的方案

- **草垛和饲料桶下面各一张两行的牌子,栅栏上一句话。** [0026](0026-pasture-screens-art.md) 的做法。负责人认为仍然不必要。
- **牌子上写全捆数,草地上方再一张写着矮中高各几株的牌子。** 第一稿。字太多。
- **感叹号用红色或者橙色。** 更抢眼,但规范里红色不当警告色。没有画出来比较过。
- **完全不加记号,只靠草垛的大小。** 草垛"矮的一堆"和"半高"的差别不足以叫住人。

## 后果

- **美术规范的"没有感叹号"有了例外:** 只在草垛和饲料桶见底时用,墨绿色。规范的"标记""够不够吃""不做什么"三处已经跟着改。
- **"还能等几天"要点一下才看得到。** "今天刚病"和"今天不治就来不及"在牧场一屏上是同一个样子:卧着,头上一个药瓶。
  这时靠的是打开牧场时那张"几天没见"的纸,而那张纸只出现一次。这和 Cocos 接入里"牛快死的时候要提前说"有出入:
  说是说了(那张纸、小屋里的每一行),但不在牧场一屏上。要不要给最后一天也加一个记号,记在[路线图](../design/06-roadmap.md#未决问题),由负责人定。
- **点开之后的几张纸字更多了。** 从屏上拿掉的话挪到了草垛的卡片、做饲料、小屋这几张纸上。
- **多了一种点法:** 点草垛。点饲料桶既是看饲料也是做饲料,两件事在同一张纸上。
- **感叹号常不常挂着,要看真人。** 每天来两次、每次把草割完的人基本看不到它;养多了的人会经常看到。挂久了它就不叫人了。
