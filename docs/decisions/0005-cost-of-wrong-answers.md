# 0005 答错的代价:不生长、扣星、枯萎、死亡

- 日期:2026-11-15(不生长、枯萎、死亡),2026-11-16(星级)
- 状态:生效
- 决定者:项目负责人

## 背景

答错必须有后果,否则答题没有分量。但后果的形式要符合种田的直觉,不能像是另一套惩罚系统。

## 决定

- 答错一次:作物不生长。
- 连续答错两次:作物枯萎。
- 连续答错三次:作物死亡,种子白费。
- 每株作物从 5 星开始,每答错一次扣 1 星,最低 1 星,收获时按星级定价。
- 答对一次,连续答错次数清零;扣掉的星不会回来。
- 只有每次浇水的第一次作答计入。答错后当场的重复练习不计。
- 缺席不算答错。错过游戏日,作物只是等着。

## 理由

- 浇水失败所以不长,一直失败所以枯萎、死亡。这套后果不需要解释。
- 星级让每株作物都有"种得好不好"的悬念,收获有了分量。
- 重复练习不计入,是为了避免一次手滑就当场连错三次。
- 缺席不受罚,是因为让人回来的应该是期待而不是焦虑(设计支柱 5)。

## 被否决的方案

- **答错后退两个阶段。** 这是最初的实现。负责人的定义是"不生长"而不是"倒退"。
- **答错的词变成害虫。** 见 [0004](0004-one-crop-one-word.md)。
- **低于四星的作物不能卖,只能做成种子重种同一个词。** 实现过,后来种子不再绑定单词,
  这条规则随之取消,见 [0006](0006-mastery-cycle-and-generic-seeds.md)。

## 后果

- 学得吃力的玩家星级低、死亡多、收入少,有被劝退的风险。这是已知问题。
- 枯萎目前只是警告,没有实际后果。
- 答错有了真实代价,所以题目必须能客观判分,见 [0010](0010-crop-type-sets-question-type.md)。
