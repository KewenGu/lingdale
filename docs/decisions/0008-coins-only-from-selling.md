# 0008 金币只来自卖作物

- 日期:2026-11-16
- 状态:生效,被 [0015](0015-mine-screens-farm-teaches.md) 扩展:金币来自卖作物和卖矿石,答题本身仍然不直接发金币
- 决定者:项目负责人

## 背景

最初每答对一题就发金币。答题的名义定为"浇水"之后,这一点变得不合情理:浇水不该直接出钱。

## 决定

- 答题和收获本身都不给金币。
- 收获的作物进入库存,卖掉才有金币。售价由星级和作物种类决定。
- 答题给的是经验。

## 理由

- 符合种田的直觉:种出来的东西卖了才有钱。
- 收获成为一个有分量的时刻,星级直接体现为价格。
- 作物死亡时一分钱都拿不到,"种子白费"才是真的损失。
- 金币和经验分工清楚:金币是这一株种得好不好的回报,经验是所有学习活动的累计。

## 被否决的方案

- **每次答对发金币。** 见背景。

## 后果

- 新玩家在第一次收获之前没有金币,所以需要每个游戏日的免费种子。
- 卖作物是一个单独的操作,界面可以提供一键全卖。
- 金币目前只能买种子和解锁地块,后期严重过剩,需要小镇内容来消耗。
