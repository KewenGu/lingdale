# 0011 名称:Lingu Town / 灵谷小镇

- 日期:2026-11-16
- 状态:生效
- 决定者:项目负责人

## 背景

项目需要正式的中英文名称。

## 决定

- 英文名:**Lingu Town**
- 中文名:**灵谷小镇**
- 仓库名:`lingu-town`

## 理由

- 中英文读音一致。Lingu 按英文读是 ling-gu,和"灵谷"对应。
- Lingu 让人联想到 lingua、linguistics,暗示语言学习。
- "灵"有灵光、灵气的意思,和学习沾边。"谷"既是山谷,也可以理解为谷物,对应把单词种成作物。
- "小镇"对应等级提升后小镇逐渐繁荣的长期目标。
- 英文名是品牌拼写,不必是拼音。

## 被否决的方案

- **林谷小镇。** 读音同样接近,田园感更朴素,但和学习没有关联,记忆点弱。
- **Linggu Town。** 严格对应拼音,但失去了 lingua 的联想,而且和南京灵谷寺的英文名 Linggu Temple 重合。

## 后果

- "灵谷"在修仙题材里指灵田里种的灵米,只看名字可能被当成修仙种田游戏。美术风格和副标题需要把预期拉回田园小镇。
- 搜索"灵谷"首先出现的是南京灵谷寺,推广时应使用全名。
- 语言学习领域叫 Lingo 的产品很多,Lingu 容易被听成或打成 Lingo。
- **尚未检查商标、应用商店和域名是否有重名。** 这需要在投入美术和宣传之前完成。
  2026-11-18 第一轮公开渠道查重发现:挪威语言培训公司 Lingu AS 自述 2015 年起"Lingu"是语言教育领域的受保护商标,
  并有一款同名语言学习应用;苏州一家公司同时使用"灵谷"和"LINGU"。详见[名称查重](../marketing/03-name-check.md)。
- 名字强调小镇,而目前的玩法几乎全在农场,小镇部分需要补上内容。
