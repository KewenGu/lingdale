# 0003 所有经验汇总成一个玩家等级,小镇的繁荣跟着等级走

- 日期:2026-11-15
- 状态:生效
- 决定者:项目负责人

## 背景

只有"种地、解锁更多地"的循环缺少长期目标。需要一个看得见在变好的东西,让玩家有盼头。

最初的提议是把小镇的变化直接绑定学习里程碑,比如掌握 100 个词修好磨坊。

## 决定

- 设立玩家等级。所有学习活动产生经验,全部汇总到同一个等级里。
- 小镇的建筑、居民等内容按等级解锁,不直接绑定词汇量。
- 经验不区分卡组和来源,只有 `addXp` 这一个入口。

## 理由

- 学习进度是多元的:不同的卡组、不同的题型、以后可能有的其他玩法。
  如果解锁条件直接绑定某一种进度,每加一种玩法就要改一次解锁规则。
- 汇总成等级后,新的经验来源只需要调用 `addXp`,小镇的规则不用动。

## 被否决的方案

- **按掌握的词数解锁小镇内容。** 直观,但把小镇和单一卡组的进度绑死了。

## 后果

- 等级和"学了多少"之间隔了一层。玩家看到等级并不知道自己掌握了多少词,
  所以词汇量和掌握度的统计仍然需要单独展示。
- 经验的权重要奖励长期记忆:浇水答对的经验随掌握度增长。
- 小镇里具体有什么还没有设计,`MILESTONES` 是占位。
