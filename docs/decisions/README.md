# 决策记录

这里记录每一个方向性的决定:当时面对什么问题、选了什么、为什么、否决了什么。

它的用途是让后来的人(包括 AI)不必重新争论已经想清楚的事,也能在情况变化时判断当初的理由是否还成立。

## 什么时候写一条

- 做了一个会影响后续很多工作的决定。
- 否决了一个看起来合理的方案,以后很可能有人再次提出。
- 推翻了之前的一条决定。

改一个数值、修一个缺陷不需要写,那些记在[数值与平衡](../design/04-economy-balance.md)的调整记录或提交信息里。

## 怎么写

文件名是 `四位编号-英文短语.md`,编号递增,不复用。内容用下面的结构,保持简短:

```markdown
# 编号 标题

- 日期:
- 状态:生效 / 已被 XXXX 取代
- 决定者:

## 背景
当时面对的问题和绕不开的事实。

## 决定
选了什么。

## 理由
为什么。从目标和事实出发,有数据就写数据。

## 被否决的方案
考虑过什么,为什么没选。

## 后果
这个决定带来的好处、代价和遗留问题。
```

推翻一条决定时,不要改写旧记录。把旧记录的状态改成"已被 XXXX 取代",然后写一条新的。
