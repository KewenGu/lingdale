# 0018 小镇地图是总入口,农场和矿洞之间另有直达;仓库并进商店

- 日期:2026-11-20
- 状态:生效
- 决定者:项目负责人

## 背景

农场的底部原来是"种子、商店、仓库"加"浇一轮水"。加入矿洞之后要再放下矿洞的入口和词袋,
还要定农场和矿洞之间怎么切换。绘制者给了三个排法(路牌加三个工具、路牌加两个工具、底部页签),
见[方案比较页](../design/mine-screens/options.html)。

## 决定

负责人三个都没有选,提出了另一个方向:

- **做一张"灵谷小镇"的地图,作为所有地方的总入口和导览。** 现在有农场、矿洞和商店;玩家还会有一个家,以后花钱买装饰、升级家装;
  以后还可以有别的地方,比如湖边钓鱼(做不同的题)、放映厅(看影视学语言)。玩家的词汇量或等级高了,陆续开放更多地点。
- **农场和矿洞之间另有一块直达的路牌**,不必每次经过地图。
- **仓库并进商店**的"卖东西"一页,不单独占一个按钮。

底部的按钮因此是:小镇、去另一处的路牌、词袋、这一屏的主要动作。种子并进了词袋和商店。

## 理由

- **名字叫小镇,就该有一个小镇。** 路线图里"小镇"一直是原型之后的事,现在它先有了一个最小的形式:一张地图。
  以后每加一个地方,都是在地图上多一处,不用再改每一屏的底部。
- **直达的路牌:** 农场和矿洞是核心循环的两头。模拟里默认场景 58% 的打开时矿洞因为田满而关着,
  玩家要去农场浇水收获再回来。只走地图的话每次往返要点两下、多看一屏,和"每天几分钟"相悖。
- **仓库并进商店:** 开局的路是"卖矿石、买种子",放在同一处少换一次地方。矿石现在只能卖,仓库还没有别的用处。
  等家开放了,仓库可以搬进家里。

## 被否决的方案

- **只走地图**(每一屏的左下角只有"小镇"):最简单,地图的存在感最强,但农场和矿洞之间每次往返多一屏。
- **底部页签**("农场 | 矿洞"):以后加地方有位置,但底部变成两排,而且页签是应用的说法。地图用游戏的说法解决了同一个问题。
- **农场底部保留仓库按钮:** 随时能看库存,但底部再多一个按钮,卖东西还是要去商店。

## 后果

- **这是一个方向性的决定,不只是界面上的。** 地图上画了"家"和"以后开放"的空地,等于向玩家许诺了它们。
  家里有什么、以后的地点怎么设计、按等级还是按词汇量开放,都还没有设计,见[路线图](../design/06-roadmap.md)。
  原型阶段仍然只做矿洞、商店、农场。
- **规则没有变。** 地图只是入口。核心层里没有"地点"的概念,等级解锁的内容仍然是占位表(`MILESTONES`)。
- **开局多了一屏。** 新玩家从矿洞去商店要经过地图。画面上的处理是第一次打开直接进矿洞,离开矿洞时才第一次看到小镇。
- **地图只有一稿,**没有比较过别的构图,地点多了之后怎么排也没有验证。
- **湖是水,而规范规定蓝色只表示能浇水。** 以后画湖边时要先解决这个冲突。
