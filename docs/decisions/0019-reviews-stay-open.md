# 0019 田满时只停新词,复习照常

- 日期:2026-11-20
- 状态:生效。修改 [0016](0016-mine-screens-farm-teaches.md) 中"额度用完矿洞关门"一条
- 决定者:项目负责人提出问题;"只停新词、复习照常"是开发时按这个问题给出的方案,需要负责人确认

## 背景

[0016](0016-mine-screens-farm-teaches.md) 规定:还能答错的次数 = 空地块数 − 词袋里的词数,到 0 矿洞关门,
到期的旧词也挖不了。

负责人指出这说不通:田种满了就不能挖矿,也就是既不能做题也不能复习。

绕不开的事实:

- 设这个额度是为了限制负担:每个答错的词都要占一块地去学,田的大小就是同时能学的词数。
- 新词答错,是真的多了一个要学的词。
- 旧词答错不一样。一个到期的旧词记不记得已经是事实,不去考它,并不会少一个要学的词,
  只会让忘掉的词晚些被发现,而且越晚忘得越多。
- 答对的词,无论新旧,都不增加负担。

所以额度该限制的只有新词。把复习一起拦住,既不减少负担,又损害学习。

## 决定

- **到期的旧词随时能挖,不受额度限制。** 答对照样出矿石。
- **田满时旧词答错,照样进词袋,排队等空地。** 词袋里的词因此可以比空地多。
- **额度到 0 时不再出新词。** 额度的算法不变:空地块数 − 词袋里的词数,最小是 0。
  排队的旧词会先占掉腾出来的空地,额度要等它们都有地方种了才恢复,所以复习仍然优先于新词。
- 矿洞挖不了的两种情况变成:额度用完且到期的旧词都挖完了(`no_room`);没有到期的旧词、新词也挖完了(`exhausted`)。

## 理由

见背景。模拟的结果(八个随机种子的平均,60 天,都是模拟数字):

| 场景 | 离开时没复习的旧词,之前 → 现在 | 60 天见过的词,之前 → 现在 | 每天题数,之前 → 现在 |
|---|---|---|---|
| 默认 | 2.1 → 0.6 个 | 679 → 682 | 120 → 122 |
| 学过的词正确率 70% | 4.7 → 0.0 | 420 → 421 | 115 → 116 |
| 一个词都不认识 | 1.4 → 0.0 | 444 → 439 | 109 → 110 |
| 每天只打开一次 | 5.1 → 0.9 | 363 → 371 | 60 → 61 |

复习基本都能做完,新词的速度和题量没有可见的变化。代价是词袋里会有几个旧词排队,各场景最多 10 个。

## 被否决的方案

- **维持原规则。** 见背景。
- **田满时新词也能挖,答错的新词在词袋里排队。** 这样"不能做题"也解决了,但额度就不存在了,
  要学的词可以无限攒下去,违反"负担自己收敛"。
- **新词可以排队,但排队有上限**(模拟了上限 30)。60 天见过的词多一成左右(682 → 755),
  但词袋里常有三四十个词等着种,新词挖到一半就停的比例也没有明显下降(66% → 59%)。
  它只是把上限挪了个位置,没有解决问题,所以没有采用。负责人如果想让玩家能多挖一些,这是现成的旋钮。
- **田满时新词也能挖,答错的不记。** 玩家看过答案之后这个词很快会再出现,靠短期记忆答对就被算成会的,
  违反学习真实性的底线。

## 后果

- **"田满了就没题可做"只解决了一半。** 复习随时能做了;新词在田满时仍然会停,这是额度本来的作用。
  到期的旧词也挖完之后,玩家仍然只能去浇水,或者等。
- **以前引用的一个数字说法不准确。** 文档和 [0016](0016-mine-screens-farm-teaches.md)、[0017](0017-mine-screens-art.md)、
  [0018](0018-town-map-as-hub.md) 里写过"58% 的打开时矿洞因为田满而关着"。模拟数的其实是"没挖满 30 次就停下"的打开,
  停下之前平均已经挖了二十来题;一打开就一题都挖不成的只有 2% 左右。现行文档已改正,旧的决策记录没有改写。
  做这次比较时才发现这一点,模拟现在会分别报告这两个数。
- **模拟低估了"没事可做"。** 模拟里的学习者每次都先浇水收获再挖矿,所以几乎每次都有空地。
  真人在两次浇水之间打开游戏的情况没有覆盖。
- **画面要改。** 矿洞这一边的示意稿是按旧规则画的:额度是 0 时还在挖旧词,界面不能写"还能答错 0 次";
  关门画面出现的时机也变了。已记入[美术规范](../design/07-art-direction.md#还没定的)和[路线图](../design/06-roadmap.md#未决问题)。
- 词袋里的词可以比空地多,"词袋里的每个词都有地方种"不再严格成立,只对新词成立。
