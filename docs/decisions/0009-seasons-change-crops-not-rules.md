# 0009 季节只换作物,不改规则

- 日期:2026-11-16
- 状态:生效
- 决定者:项目负责人(季节与作物),跨季细则由开发时确定

## 背景

讨论长期复习的形式时提出过用季节来承载:新的季节、新的作物、新的单词循环。
后来长期复习改由掌握度循环负责([0006](0006-mastery-cycle-and-generic-seeds.md)),
但季节作为日历和变化感的来源保留了下来。

## 决定

- 28 个游戏日一季,也就是现实 2 周;四季一年。
- 每个季节有自己的一套作物,每种题型各一种。
- 季节不改变任何生长、品质、掌握度的规则。
- 换季时地里的作物不会枯死,照常生长。
- 种子跨季不作废,在新季节种下就长成新季节的作物。

## 理由

- 每两周换一批作物外观,给长期游玩带来变化,成本只是美术。
- 学习规则不随季节变化,否则同一个词在不同季节的学习效果不一致,没有道理。
- 换季作物枯死在星露谷里是为了制造季节规划的压力。这里作物承载的是学习进度,
  枯死等于白学;而且每季最后两天没人敢播种。
- 过季种子作废同理:种子承载的是学习机会,作废只是浪费。

## 被否决的方案

- **照搬星露谷:换季作物枯死、过季种子不能种。** 见理由。
- **用季节做长期复习的节拍。** 见 [0006](0006-mastery-cycle-and-generic-seeds.md)。

## 后果

- 种子在存档里按题型记录,不按作物记录。界面上显示为当季对应作物的种子。
- 需要 12 种作物的美术。
- 库存里会同时存在不同季节的作物。
