# 0030 答完之后选项那一块要安静,有字的板子不歪:游戏效果不抢学习内容

- 日期:2026-11-22
- 状态:生效。修改[美术规范](../design/07-art-direction.md#矿洞)里矿洞答完之后的画法;动效还没有做,够不够有游戏感没有验证
- 决定者:项目负责人

## 背景

矿洞拆成素材之后([新画风的画面](../design/cel-screens/README.md#用素材拼出来的矿洞)),答对、运气好、答错第一次按新画风画了出来。
排法照搬彩纸那一屏:词牌右上角探出这次会出的矿石;答完之后镐落在被点的那条石板上;答对时矿石放大摆在洞口,下面贴一条写着名字的纸;
运气好时上方再压一条玉米黄的纸带。

负责人看过之后前后说了三次(原话):

> 单词框右上角的矿石预测就不用加了,然后镐子不用在答对答错的选项上显示,还是跟原来一样固定在矿洞的一角就可以

> 那稿还是放回去吧

> 我觉得视觉效果的影响了,就是这个题目选项的文字的显示。这就是游戏效果跟这个学习目的相违背的地方。这个游戏效果太强了,会导致这个学习会被 distract。

第二句我理解成把镐放回石板上,照做了一版;这个理解可能是错的。现在的画面按第三句来。

**量出来的(绘制时量的,脚本是 [`tools/text_cover.mjs`](../design/cel-screens/tools/text_cover.mjs)):**

- 字没有被盖住。示意稿用的四条释义一个像素都没有被效果盖住;换成示例卡组里最长的四条(12 到 14 个字),答对时盖住 1.1%。
- 字和石板的明暗对比是 7.3,彩纸是 7.2。
- 效果在四条石板那一块里占的面积:答对 4.0%,运气好 8.8%,答错 1.1%。

所以问题不在遮挡,在抢眼。

## 决定

**答完的那一刻,四条石板那一块只留和答案有关的东西。** 具体到矿洞:

| | 之前 | 现在 |
|---|---|---|
| 词牌右上角 | 探出这次会出的矿石 | 不放 |
| 镐 | 答完落在被点的那条石板上 | 一直靠在洞的一角 |
| 挖出的矿石 | 放大 2.4 倍摆在洞口,压到上面一条 | 1.5 倍,留在挖开的洞里,不出自己那一条 |
| 矿石的名字、"运气好" | 贴在石板之间 | 写在最下面那一行 |
| 石板上的字 | 答对的那条折行变窄 | 所有状态按同一个宽度折行,答完不重排 |
| 答错的那条石板 | 右端一个浅坑,镐停在上面,整条多歪 2.2 度 | 右端一个明显的坑,裂纹向四周散开,占右边三分之一;没有镐,不歪 |
| 词牌和石板的角度 | 词牌歪 1.2 度,石板各歪不到 1 度 | 都是正的 |

改完之后效果占的面积:答对 0.6%,运气好 1.4%,答错 0.6%(答错剩下的是正确答案上的对勾);被盖住的字都是 0。
这个数只是面积,不是"有多抢眼"的度量,抢不抢眼最后要人看。

**答错的那条是之后补的。** 镐拿走之后它只剩一个小坑,负责人看过之后要求"答错的词板再弄明显一点"。加强的是形状(坑和裂纹),
没有用红色和叉([美术规范](../design/07-art-direction.md#用色规则)),裂纹不进字的地方。

**有字的板子不歪,也是之后补的。** 负责人的原话:"我不想要词板或者卡片歪来歪去,影响阅读体验。"
彩纸那一屏里的歪是为了像手贴的纸片;新画风里词牌和四条石板都摆正了。这一条不只管矿洞:以后带着要读的字的板子和卡片都不歪。

## 理由

负责人的理由是原话里那一句:游戏效果太强会让学习分心。

下面是我补的,不是负责人说的:

- 答完的那一刻是学习发生的时候,尤其是答错:这时要看的是词、正确的释义、自己选错的那条。镐压在选错的那条上,是把眼睛引向错的答案。
- 这不违反"答题就是游戏动作"([设计支柱](../design/01-vision.md#设计支柱) 1)。那一条说的是点选项的那一下就是那一镐,
  管的是动作,不是答完之后画面上要留多少东西。动作可以只占一瞬间:镐从洞边挥过去再回来,矿石跳一下再落进洞里。

## 被否决的方案

- **镐停在被点的石板上**(彩纸那一屏的做法)。做过,负责人看过之后提出了上面的意见。
- **只把效果挪开、不让它压到字。** 量出来字本来就几乎没被盖住,挪开解决不了抢眼。

## 后果

- **静止的画面比之前平淡。** "挖到矿石的高兴"现在要靠动效和声音,而动效还没有做。这是没有验证的一头:
  如果做出来之后答对不够痛快,要回来调,调的是那一瞬间的动效,不是把东西放回选项上。
- **旧词石板上露着的那点矿没有动。** 它是读题时石板上唯一的装饰(占 1.2%),也是一种矿石预告。负责人没有提到它。
- **割草那一屏是同一种做法**(词牌探出能割的草,镰刀落在被点的那一垄上,词牌和草垄也是歪的),没有重做,到时候按这一条来。
- **答错时落向词袋的那张小纸签还歪着**(13 度)。它是落下去的东西,不是用来读的;负责人说的是词板和卡片,所以没有动。
- 美术规范的正文还是原来的写法,开头的说明里记了这一条,等重写时改。彩纸的那一屏没有动。
- 没有问过任何目标用户。
