# 名称查重

对外发布内容之前必须完成名称查重(见[内容策略](01-content-strategy.md#红线))。本文记录查了什么、查到了什么、还剩什么没查。

**这不是法律意见。** 下面是公开渠道能查到的信息,商标是否构成冲突,要以商标局的正式检索和专业意见为准。

## 2026-11-18 第一轮:公开渠道

### 查了什么

| 渠道 | 查询词 | 方法 |
|---|---|---|
| App Store 中国区、美国区 | Lingu Town、Lingu、灵谷小镇、灵谷、Lingo Town | Apple 公开搜索接口 |
| Steam | Lingu Town、Lingu、灵谷 | Steam 商店搜索接口 |
| 网页 | "灵谷小镇"、"Lingu Town"、相关公司和商标 | 搜索引擎 |
| 域名 | lingutown.com 等 7 个 | RDAP 注册信息查询 |

### 结论

**完全同名的:没有找到。** "灵谷小镇"和"Lingu Town"在 App Store、Steam 和网页上都没有同名的产品。

**但 "Lingu" 和 "灵谷" 各有一个需要重视的在先使用者:**

#### 1. Lingu AS(挪威),风险高

- 挪威的语言培训公司,2008 年成立,既做在线教育产品也办语言学校。
- 它在 App Store 上有一款就叫 **Lingu** 的应用,分类是教育,教挪威语和英语,中国区和美国区都能搜到。
- 它的官网历史页写着:**2015 年 3 月,Lingu 成为语言教育领域受保护的商标。** 这是公司自述,我们没有在挪威或欧盟的商标库里核实注册详情。
- 2025 年 12 月收购了一家英国公司,官网称这是它**进入全球英语培训市场**的第一步。

和我们的关系:同一个词、同一个领域(语言学习),对方已经在做英语,并且在向国际扩张。
"Lingu Town" 用在语言学习应用上,和它构成近似的可能性很高。国内市场是否受影响,取决于它有没有在中国注册,目前不知道。

#### 2. 灵谷优优科技(苏州)有限公司,风险待查

- 英文名是 LINGU YOYO TECHNOLOGY (SUZHOU) CO., LTD.,同时在用"灵谷"和"LINGU"。
- App Store 上有两款应用:**灵谷优优**(握力康复训练,健康类)、**灵谷优护**(护士学习平台,医疗类)。
- 后者是一个学习平台,和教育类有交集。它在国内是否注册了"灵谷"或"LINGU"商标、注册在哪些类别,没有查到。

和我们的关系:"灵谷小镇"在国内上架时,如果对方在软件、教育类别注册了"灵谷",可能构成近似。

#### 其他

| 名称 | 情况 | 风险 |
|---|---|---|
| 万灵谷 | App Store 上的 AR 恐龙卡牌游戏 | 低,名称不同 |
| 灵谷寺、灵谷洞 | 南京、宜兴的景点 | 不是商标冲突,只影响搜索,已在[决策记录 0011](../decisions/0011-name.md)里考虑过 |
| Lingokids Town | 儿童教育游戏 | 低,但说明"语言学习 + Town"的命名方式并不少见 |
| Lingumi(面包英语) | 儿童英语启蒙 | 低,名称不同 |

| lingu.town | 未注册 |
| lingutown.app | 未注册 |
| lingutown.games | 未注册 |

查询的可靠性已经用已知注册的域名验证过(.com、.app、.town、.game、.games 都能正确识别已注册的域名)。
.cn 不支持这种查询,需要在国内注册商那里查。名称定下来之前不建议注册。

## 2026-11-18 第二轮:英文名候选

第一轮发现 "Lingu" 在语言教育领域有在先使用者,所以列了一批保留"灵谷小镇"、只换英文名的候选,用同样的公开渠道过一遍。

**候选的思路**:要么呼应"灵谷"的读音(Ling- 开头),要么呼应"词汇 + 山谷"的意思(Lexi-、Word- 开头加 -vale、-dale)。
避开 Lingo、Lingu 这类已经很拥挤的词根。

| 候选 | App Store(中、美) | Steam | 同名网站 | 判断 |
|---|---|---|---|---|
| Lingvale | 无 | 无 | lingvale.com 于 2026-10 注册,是**在线英语课程** | 淘汰,同领域在用 |
| Wordvale | 无 | 无 | wordvale.com 于 2026-07 注册,是**词汇学习应用** | 淘汰,同领域在用 |
| Wordsprout | 有 5 款同名或近名的词汇应用 | 无 | .com、.app 都已注册 | 淘汰,同领域很拥挤 |
| Lingrove | 无 | 无 | lingrove.com 是墙面材料品牌;lingrove.app 已注册,用途不明 | 不推荐,.app 已被占 |
| Lexidale | 无 | 无 | lexidale.com 是国际政策咨询公司 | 可用,但领域不同的同名公司会分散搜索 |
| **Lexivale** | 无 | 无 | lexivale.com 2014 年注册,空页面 | 可用 |
| **Lingdale** | 无 | 无 | lingdale.com 2016 年注册,空页面 | 可用 |
| **Linggu Valley** | 无 | 无 | .com、.app 都未注册 | 可用,但和灵谷寺、灵谷洞同名 |

几个可用候选的域名:

| 候选 | .com | .app | .games |
|---|---|---|---|
| Lingdale | 已注册(空页面) | 未注册 | 查询被限流,未知 |
| Lexivale | 已注册(空页面) | 未注册 | 未注册 |
| Linggu Valley | 未注册 | 未注册 | 查询被限流,未知 |

网页搜索也没有找到使用 Lingdale、Lexivale、Lexidale 的产品或公司(除上表的网站外)。

和第一轮一样,这只是公开渠道,商标局的正式检索还没做。

## 还没查的

这些需要人工操作(有验证码或需要登录),或者需要商标代理:

| 渠道 | 要查什么 |
|---|---|
| 国家知识产权局商标局 | 灵谷、灵谷小镇、LINGU、LINGU TOWN,重点看第 9 类(软件)、第 28 类(游戏)、第 41 类(教育、娱乐)、第 42 类(软件服务) |
| WIPO 全球品牌数据库 | LINGU、LINGU TOWN 的国际注册,尤其是 Lingu AS 有没有指定中国 |
| 挪威专利局、欧盟知识产权局 | 核实 Lingu AS 的商标注册详情 |
| 美国专利商标局 | LINGU、LINGU TOWN |
| 小红书、抖音、公众号、B 站、小黑盒 | 账号名"灵谷小镇"是否已被占用 |
| 安卓应用商店 | 灵谷小镇、Lingu Town |
