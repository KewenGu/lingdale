灵谷小镇是我正在做的一个游戏:把背单词做成种田。一株作物就是一个单词,浇水就是答题。

游戏还没有画面。动手做农场之前,我得先决定它长什么样。

所以我把同一片农场画了四遍。

## 四种画风

四张图画的是同一个存档:30 块地,12 块等着浇水。只有画风不同。

- **A 像素菜园。** 像素画,像一块小小的电子菜园,颗粒分明。
- **B 水彩绘本。** 铅笔线、淡彩、纸的纹理,安安静静的。
- **C 彩纸拼贴。** 一片片剪出来、贴起来的农场,颜色干净。
- **D 低多边形。** 像摆在桌上的积木沙盘,有体积有影子。

先说明一点:这些都是用代码画的示意稿,不是成品,代码是 AI 协助写的。我用它们来比较方向,不是比谁画得精细。

## 我看的不只是好不好看

这个游戏里,农场就是你记忆的样子。你每天打开它,扫一眼,就该知道:

- 哪些作物今天还没浇水(也就是哪些词今天还没复习)。
- 哪些蔫了。一个词答错一次,它那天不长;连着答错两次,它就蔫了。
- 哪些就差一步能收获了。

所以我给每种画风出了同一道题:把农场缩得很小,这些还看不看得出来?

地块以后最多会有 120 块,是现在的四倍。到那时如果想一屏看全,每块地的边长不到现在的一半。

## 我自己最喜欢 C

【创作者:你为什么喜欢 C。用你自己的话写,写你看到它时的感受。下面是可以用的事实,不是替你写好的理由。】

可以用的事实:

- 缩小之后 C 最清楚。浅色的土是该浇水的,深色的土是浇过的,蓝色水滴一眼就能找到。水彩缩小后最先糊掉。
- C 的作物是一片片纸拼的。作物蔫了,就是把叶子那几片纸转下去、换个颜色,不用每种作物重新画一张。
  我是一个人在做,这一点很要紧。画像素稿的时候试过用程序让作物"蔫",效果明显差,得一张张手画。
- 这个游戏的正文是单词和释义,字必须好读。像素字体在这里吃亏。

## 但我也有不确定的地方

【创作者:你自己的顾虑。下面是探索时列出来的风险,选你认同的写。】

- C 是四个里最容易看起来像"一个应用"的,而我想做的是一个游戏。
- B 的水彩最治愈,也最不像一个学习软件。我没选它,是因为它缩小之后状态最难认,而且每一张都要画得像同一个人画的,对一个人来说太难。
- 这几张图是用代码画的,而代码最擅长画的恰好是 C 这种纯色块。水彩和 3D 用真正的工具做,会比这里好看得多。所以这次比较对 C 有利。

## 想听听你的

你更喜欢哪个?A、B、C 还是 D?喜欢它的什么?

我已经打算照 C 做下去,但细节还没定:颜色要不要更柔和,要不要更有手作的感觉,要不要向水彩借一点纸的质感。
你的看法会影响这些。等定下来,我会回来讲最后做成了什么样、哪些意见用上了、哪些没用上和为什么。
